## 它做什么

`learn-one-concept` 用一个短而完整的互动回合，帮助你真正理解一个已点名的概念。它不以漂亮定义或做完笔记为终点，而要求你脱稿解释、在情境中判断，或尝试一个最小行动。

它一次只处理一个概念；整章材料、一套方法论或多个并列概念需要先缩小范围。

## 何时使用

你通过输入 `/learn-one-concept <概念>` 调用它；模型不会自行调用。

| 你的处境 | 该选什么 |
| --- | --- |
| 有一个点名概念，想立即学懂并检验理解 | `/learn-one-concept` |
| 需要先梳理一本书、文章或视频的结构 | [`learn-modeling`](learn-modeling.md) |
| 想围绕真实问题开展持续课程 | [`teach-me`](teach-me.md) |
| 已经学完，想把指定概念保存为笔记 | [`concept-card`](concept-card.md) |

来源可以由你提供；没有来源时，会先寻找可靠资料，并明确仍缺少的证据。

## 一轮，而不是一份摘要

它的核心是**一轮**：人话含义、定义与边界、最短机制、和当前问题的关系，最后都要落到你的解释、判断或行动。输入在可能改变判断的地方暂停；反馈针对定义、边界、关系或适用条件的具体差距。

若你明确希望保存，本轮可以复用 `concept-card`；概念卡是笔记工件，不是掌握证明。

## 常见问题

**我只答对一次，算学会了吗？**

不算。一次回答只是当前理解的证据；稳定掌握还需要独立表现或在新情境中的迁移。

**它和概念卡有什么区别？**

这里的重点是互动学习和展示；概念卡的重点是把一个已指定的来源片段保存为可回溯的工件。

## 有效的信号

- 概念、来源和本轮目标都已锁定。
- 你亲自完成了一次解释、判断或微行动，并得到了针对性反馈。
- 结束时知道证据支持了什么、还缺什么，以及唯一的下一步。

## 它在流程中的位置

它是随时可用的短路径。已安装上游 `/grill-me`（它运行 `grilling` 访谈）的学习者可用 `/grill-me → /learn-one-concept`，先把现实问题收窄为一个概念；`/grill-me` 不属于本仓库。若需要本仓库内的学习使命质询，可先用 [`grill-with-learn`](grill-with-learn.md)。它不替代跨会话的 [`teach-me`](teach-me.md) 或检查点式的 [`study-review`](study-review.md)；不确定该选哪个入口时使用 [`ask-ming`](ask-ming.md)。
