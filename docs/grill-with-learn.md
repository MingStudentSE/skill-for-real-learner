# Grill with Learn

输入 `/grill-with-learn`，通过项目内的 [grilling](grilling.md) 澄清学习使命、计划或当前决策。指定书、文章、视频或概念本身阻塞判断时，按需复用 [learn-modeling](learn-modeling.md)，理解材料后继续讨论。

这是对官方 `grill-with-docs` 的薄适配：质询方法由 `grilling` 提供，内容建模由 `learn-modeling` 提供。它不默认建立模型，也不默认写学习计划。

## 何时使用

| 处境 | 入口 |
| --- | --- |
| 学习目标、现实卡点或取舍说不清，材料理解可能影响判断 | `/grill-with-learn` |
| 只需要质询计划或想法 | [grill-me](grill-me.md) |
| 长期方向和精力配置需要决定 | [strategyfinder](strategyfinder.md) |
| 已有学习共识，需要定制计划 | [to-plan](to-plan.md) |
| 想学习、练习并检验一个概念 | [teach-me](teach-me.md) |

## 有效信号与交接

学习者能说明真实问题、当前选择与约束；事实、偏好、假设和未知保持区分；仅在需要时留下有来源导航的内容模型。

达成共识后，可以手动运行 `/to-plan`。本入口不会自动进入计划、任务或教学，也不把学习模型当作掌握证据。运行正文见 [SKILL](../skills/learn/grill-with-learn/SKILL.md)。
