## 它做什么

`learn-modeling` 把你指定的书、文章、视频、课程讲义或文件，按原材料的章节顺序整理成学习者可读、可回到原文的学习模型。模型区分核心与延伸内容、原材料内容与补充解释，并保留概念关系、前置知识桥、学习难点和来源导航。

它建立的是**学习模型**，不是课程、练习记录或掌握证明；材料的章节地图不能代替学习者自己展示能力。

## 何时使用

你可以手动输入 `/learn-modeling`；当当前学习流程确实需要材料结构时，模型也可以复用它。

| 你的处境 | 该选什么 |
| --- | --- |
| 指定材料看不懂，需要结构、关系和难点地图 | `/learn-modeling` |
| 只想互动学懂一个已点名概念 | [`learn-one-concept`](learn-one-concept.md) |
| 需要围绕真实问题讲解、练习和反馈 | [`teach-me`](teach-me.md) |
| 想保存一个指定笔记概念 | [`concept-card`](concept-card.md) |

## 前提条件

需要可访问的指定材料。长材料可以分批建模，但每次必须明确已实际处理的章节范围；目录、搜索摘要或记忆不能被当作已覆盖的原材料。

## 忠实的内容模型

它的核心是**学习模型**：既维持原材料的章节逻辑，又把读懂当前内容真正需要的背景、概念关系和难点讲清楚。每一项重要内容都标为“原材料内容”或“补充解释”，让读者知道哪些来自来源本身，哪些是为了理解而增加的说明。

模型默认写入 `learning-models/<date>-<topic>.md`；同一材料的新范围和更准确的来源定位应更新同一模型，并保留覆盖范围的变化。

## 常见问题

**这等于把整本书摘要一遍吗？**

不是。它保留完整内容地图和章节关系，但不逐句复述；对未实际读取的部分必须诚实标记为待覆盖。

**有了学习模型就算学会了吗？**

不算。模型只降低理解材料的门槛。互动教学、任务和复盘仍需要学习者自己的判断、行动和证据。

## 有效的信号

- 已覆盖范围和待覆盖范围明确，没有夸大材料完成度。
- 概念关系、前置知识、难点和来源位置足以支持后续学习。
- 原材料内容与补充解释可区分，读者能回到来源核对。

## 它在流程中的位置

这是可共享的基础能力：[`teach-me`](teach-me.md) 或 `grill-with-learn` 在确有材料结构需求时可以复用它。它也可独立运行；选择更合适入口时使用 [`ask-ming`](ask-ming.md)。
