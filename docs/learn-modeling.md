## 它做什么

`learn-modeling` 把你指定的知识范围整理成学习者可读、可回到来源的模型笔记。范围可以是一本书、一篇文章、一段视频、一个章节、笔记片段，也可以只是一个点名概念。

它只提供一个入口，内部根据范围选择格式：材料模型保持原材料顺序，概念模型围绕问题、定义、边界、关系和例子组织。

## 何时使用

你可以手动输入 `/learn-modeling`；当前学习流程需要模型笔记时也可以复用它。

| 你的处境 | 该选什么 |
| --- | --- |
| 想梳理一本书、文章、视频或章节的结构与难点 | `/learn-modeling` |
| 想把一个点名概念整理成可回溯的模型笔记 | `/learn-modeling` |
| 想通过提问、讲回和反馈真正学懂一个概念 | [`learn-one-concept`](learn-one-concept.md) |
| 需要围绕真实问题持续讲解、练习和反馈 | [`teach-me`](teach-me.md) |

## 前提条件

需要一个明确知识范围和可访问来源。长材料可以分批建模，但每次必须标明实际覆盖范围；目录、搜索摘要和记忆不能被当作已经覆盖的来源内容。

单个概念需要被明确点名。宽泛主题、整节材料或多个并列概念会按材料范围建模，避免把一组内容挤进一张概念模型。

## 一种能力，两种内部范围

- **材料模型：** 保持来源的章节或段落顺序，保留内容总览、核心与延伸、前置知识、概念关系、难点、覆盖范围和来源导航。
- **概念模型：** 围绕一个概念要回答的问题，写清定义、机制、边界、2–4 个必要关系、正反例、应用假设和来源导航。

两者都区分原材料内容、补充解释、学习者假设与未知，并默认写入 `learning-models/<date>-<topic>.md`。同一范围不会同时生成两份重复笔记。

## 常见问题

**给一个概念做笔记，需要另一个 skill 吗？**

不需要。概念只是 `learn-modeling` 能处理的最小建模范围。

**有了学习模型就算学会了吗？**

不算。模型降低理解门槛，但不会证明你能独立解释、判断或行动。需要互动学习时使用 `learn-one-concept` 或 `teach-me`。

## 有效的信号

- 建模范围与来源可核对，未读部分没有被写成已覆盖。
- 所用结构与范围一致：材料保留来源顺序，单概念围绕问题和边界展开。
- 概念关系、难点、例子和来源位置足以支持后续学习。
- 原材料内容、补充解释、学习者假设与未知没有混淆。

## 它在流程中的位置

这是可共享的知识建模能力。`teach-me` 可以用它准备材料结构；[`learn-one-concept`](learn-one-concept.md) 可以在学习者选择保存时用它建立概念模型。它不记录学习过程、安排任务或判断掌握；不确定入口时使用 [`ask-ming`](ask-ming.md)。
