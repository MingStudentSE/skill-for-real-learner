# Grill Me

输入 `/grill-me`，通过官方质询流程澄清计划、决策或想法。它是一个显式入口，调用本项目内的 [grilling](grilling.md)，无需另装上游套件。

适合需要检验假设、识别关键取舍并形成共识的讨论。有效信号是问题围绕尚未确定的决定推进，每轮提供建议，回答后再展开依赖这些决定的下一层问题；实现工作在达成共识后开始。

只需质询时使用本入口；指定学习材料阻塞判断、需要按需建立内容模型时，使用 [grill-with-learn](grill-with-learn.md)。本入口不强制创建学习计划或模型文件。

[运行正文](../skills/up-stream/grill-me/SKILL.md)与界面配置原样来自 [Matt Pocock Skills](https://github.com/mattpocock/skills/tree/5beb35b040e3de97e54fa9e386d7e42d15c295c2/skills/productivity/grill-me)，同步提交为 `5beb35b040e3de97e54fa9e386d7e42d15c295c2`。
