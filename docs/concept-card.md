## 它做什么

`concept-card` 把一个已经指定的笔记片段或材料中的概念，整理为可回溯、可判断、可行动的 Markdown 概念卡。卡片从它要解释的真实问题出发，写清定义、边界、最小概念关系、正反例、来源与仍待验证的部分。

它只做一个选定概念；不会把整篇文章、零散摘录或概念地图伪装成一张卡，也不会擅自保存或覆盖笔记。

## 何时使用

你可以手动输入 `/concept-card`；当当前学习流程需要复用一个明确的概念工件时，模型也可以调用它。

| 你的处境 | 该选什么 |
| --- | --- |
| 已选定一个概念和其来源范围，想保存为可用笔记 | `/concept-card` |
| 还没有选定一个概念，想先互动学懂它 | [`learn-one-concept`](learn-one-concept.md) |
| 需要整理整篇材料的章节结构 | [`learn-modeling`](learn-modeling.md) |
| 需要检验一段学习是否有效 | [`study-review`](study-review.md) |

## 前提条件

提供一个明确的概念和最小来源范围，例如粘贴片段、笔记路径与标题/段落，或已有学习模型中的点名概念。没有可靠来源定位时，卡片会保留“待补”，而不是编造出处。

## 最小概念束

它的核心是**最小概念束**：只连接理解或使用当前概念最必要的 2–4 个相关概念，并标明它们是前提、组成、因果、对比还是应用条件。卡片还要让概念落地：一个正例、一个易混淆反例，以及能检验判断或行动的最小情境。

默认在对话中交付；只有你明确要求保存到某个新文件时才写入。卡片是理解和判断工件，不自动成为学习记录、任务或掌握证明。

## 常见问题

**它和 `learn-one-concept` 有什么不同？**

这里的目标是从已指定来源产出可回溯的笔记；后者通过互动讲解、展示和反馈帮助你学懂一个概念。

**一张卡完成后，能说明我掌握了吗？**

不能。卡片可以支持后续判断与练习，但掌握仍需要独立解释、迁移或真实行动证据。

## 有效的信号

- 卡片有一个明确问题、边界清楚的定义、少量有标签的关系和可辨别的正反例。
- 来源事实、教学解释、学习者假设和未知被清楚区分。
- 卡片提供了一个真实或构造情境中的判断/行动检验，而不是只有术语定义。

## 它在流程中的位置

这是可共享的概念工件能力。它可以在 [`learn-one-concept`](learn-one-concept.md) 的学习者明确选择保存后被复用，也可独立处理已有笔记。对整个工具集的入口选择见 [`ask-ming`](ask-ming.md)。
