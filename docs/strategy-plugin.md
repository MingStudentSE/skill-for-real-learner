# 学习工作台

这是统一的 DeepSeek Harness 学习工作台插件。每个 skill 对应一个功能，逐个实现、逐个验收，后续功能继续加入同一个插件。

当前第一个已实现功能是学习战略（`strategyfinder`），默认折叠在工作台的功能列表中，点开后才展开；计划、任务、课程等功能尚未实现，本轮不展开。

## 界面形式

工作台采用固定框架：顶部为当前学习战略文件夹、刷新与文件夹设置，左侧为已实现功能列表，中间为业务内容，底部显示文件快照和功能状态。工作台首页由功能卡、战略文件夹快照和工作台规则组成，不默认展开内容；点开学习战略后，才显示“方向与取舍、决策地图、真实测试、战略记录”四个视图与业务面板，可通过面包屑“功能”返回列表。后续 skill 继续加入同一份功能列表。

设计语言是“书房工作台”：暖纸背景、墨色正文和深绿强调；页面标题与长期方向用宋体，操作与正文用系统无衬线，数据使用等宽数字。状态同时用文字与颜色表达，表格、依赖图和并排对照保持低装饰。宽屏保留左侧功能栏；容器窄于 980px 时改为顶部视图标签，窄于 720px 时投入表转为逐行卡片，640px 以下进入单列布局。文本对比按 4.5:1 核对，焦点环常驻，窄屏触控目标提升到 44px，并支持减少动态效果。

## 交互

- **层级只有一层进出**：工作台目录 → 学习战略 → 四个视图；面包屑“← 功能”返回目录，功能标题也可收起。进入功能或切换视图时焦点落到页面标题，返回目录时落到“功能”标题，避免键盘焦点丢失。
- **保留当前上下文**：视图、决策筛选、搜索词、关系图开关和选中的决策卡在功能内保留；返回目录再进入仍回到上次视图。切换学习战略文件夹时重置视图和筛选。
- **详情不打断判断**：宽屏时决策详情与依赖图/列表并排；窄屏时详情接管内容区并显式提供“决策列表”返回。打开详情时保存列表滚动位置并把焦点移入详情，关闭时恢复滚动位置和原列表行的焦点；`Esc` 也可关闭详情。
- **键盘可达**：第一个 Tab 是“跳到功能内容”；`/` 聚焦决策搜索，`Esc` 清空搜索，`⌘/Ctrl + Enter` 提交战略讨论。图节点、列表行、筛选和弹窗都可用键盘操作。
- **设置防丢失**：学习战略文件夹设置只有一个入口；修改后点取消会先确认是否放弃，设置期间禁用刷新和功能切换；保存后显示“已重新读取”提示。加载失败可直接重试，或回到文件夹设置。
- **反馈紧邻操作**：讨论提交后保留提示并提供“刷新资料”；决策搜索显示“显示 X / Y 张”并在无结果时提供清除筛选；空地图在有决策卡时提供“查看决策地图”。
- **不接管宿主路由**：工作台不修改浏览器 URL，也不提供跨会话深链；当前面板内的状态在刷新后回到功能目录，这是宿主拥有会话路由的边界。

界面参考了本地内容工作台常见的“业务面板 + Harness 原生对话”布局：

- 在支持工作台服务的 DSH Desktop 中，插件尝试注册业务面板（默认左侧 70%），原生会话由宿主放在另一侧；选中战略内容后仍通过原生会话讨论。
- 在普通 Harness Web 中，工作台作为独立页面从左栏入口打开，不嵌入新会话主页；页面内不仿造聊天输入框。
- 当前通用安装包没有单独声明 DSH Desktop 的客户端加载依赖，Desktop 双栏模式尚未完成安装实测；离线预览右侧的原生对话只是布局示意，不是可交互会话。

## 看什么、做什么

- **方向与取舍**：长期方向、实际投入、结果与沉淀、下一阶段投入、相应减少什么，以及护栏、复利假设与明确不做。
- **决策地图**：用有向关系图呈现明确的前置依赖；列表可搜索和筛选可推进、受阻及原始状态；点选后查看判断、事实、自述、推断、未知和关闭条件。
- **真实测试**：把投入上限、观察信号、停止条件与实际反馈、投入取舍并排阅读；点击“带回测试反馈”继续战略讨论。
- **战略记录**：查看地图修订和已结束的问题，保留放弃与不再相关的记录。
- **讨论战略**：用户显式点击后，在所选战略文件夹关联的 Workspace 中创建原生会话并提交 `/strategyfinder`，由技能开展讨论与维护文件。全局只有一个讨论入口，位于功能标题栏；决策卡和真实测试里的按钮只针对该条内容，战略文件夹设置也只有一个入口。

没有可比数字时保留定性内容，不计算 ROI、得分或占比；缺失状态不推断为待推进。测试安排、测试完成与假设已被证明不能相互替代。

## 安装与入口

插件目录：[learning-workbench](../plugins/learning-workbench/README.md)。包名 `dsh-learning-workbench`。

1. 使用已经构建的本地插件目录，或下载打包文件后解压到一个固定位置。
2. 在 Harness 设置的 Plugins 页面选择 Add plugin，添加该插件的绝对目录。目录根应能看到包清单与 `cordis.patch.yml`。
3. 完成安装后刷新当前 Harness 页面。没有承诺仅保存源文件就能热更新。
4. 从左栏“学习工作台”进入；首次选择一个学习战略文件夹，再点开学习战略功能。

接口按本机安装的 Harness **0.2.1-rc.3**（`be72761ee1a6736ebcdf4f3739363b083ae53c98`）核对。浏览器渲染与交互、Host/会话适配自动测试通过，不等于已在用户已登录的宿主里完成安装和真实模型会话实测。旧版、Dataelem Desktop 私有扩展和未来版本不能默认等价。

普通 Harness Web 只保留左栏“学习工作台”入口和独立页面，不嵌入新会话主页。整张首页替换需要宿主提供组合接缝，当前插件不抢占已有 single slot。

## 启动故障恢复

如果安装后 Harness 无法启动，先完全退出应用。启动日志位于 macOS 的 `~/Library/Logs/DeepSeek Harness/crash-*-web-boot.log`。出现 `Identifier 'apply' has already been declared` 是 0.2.0 客户端打包缺陷，0.2.1 修复了启动崩溃；0.2.2 修复了启动后界面失去样式的问题，样式现在随工作台组件渲染；0.2.3 修正了工作区与会话接口的返回结构；0.2.4 补上 `remote.session` 注入和会话/工作区客户端加载依赖；0.2.5 移除了新会话主页嵌入，普通对话保持 Harness 原样，学习工作台只从左栏进入；0.2.6 改为默认折叠的功能模块：工作台先显示功能列表，点开学习战略才展开视图与内容；0.2.7 移除重复入口：不再在顶部重复提供项目选择器，空状态不再重复“开始战略讨论”；0.3.0 重做界面：书房式暖纸配色与宋体标题、功能目录与项目快照、响应式顶部标签栏、移动端表格卡片化，并修复窄屏 onboarding 溢出；0.3.1 重做交互：视图/筛选/详情状态保留、焦点与滚动恢复、搜索与提交快捷键、设置未保存确认、讨论后的刷新入口和空状态动作；0.3.2 把设置收敛为一个学习战略文件夹，地图与决策卡从该文件夹及其中配置读取。也可以先从 profile 的 `package.json` 移除 `dsh-learning-workbench` 依赖并删除对应 `node_modules` 链接，恢复启动后再重新安装。

不要为了恢复启动而删除学习战略文件夹、会话或 `~/.dsh` 整个目录。

## 选择学习战略文件夹

第一次选择一个真实文件夹的绝对路径。可用宿主目录选择器，也可手动输入；取消选择保持原状。插件把这个文件夹当作战略工作区，直接读取其中的 `STRATEGY-MAP.md` 和 `strategy-decisions/`；不再另外填写项目、地图或决策卡路径。

地图与决策卡在这个文件夹内的其他位置时，在文件夹内的 `docs/agents/learning.md` 用路径表映射“长期战略地图”和“战略决策卡”。配置相对这个文件夹，不推测任意自然语言，也不扫描其他目录。支持已有嵌套目录，不移动原文件。

空文件夹也可打开并启动战略讨论，不自动创建学习环境、计划、任务或课程。未发现工件时保留空状态。选择与阅读操作不写战略文件；点击讨论后才由原 skill 按其用户确认边界维护地图与卡。

旧版本保存的“空间 + 项目”会合并为同一个战略文件夹；旧的自定义地图、卡目录和配置指针不再从表单传入，需要时写进该文件夹内的配置。

插件仅在当前浏览器持久化文件夹路径；跨浏览器不会自动同步。切换文件夹不改变已有会话目录。会话创建以该文件夹登记 Workspace。

## 数据与刷新

战略地图与决策卡仍是权威来源。每次刷新读取该文件夹快照；没有另存学习进度。修改文件后可手动刷新，讨论结束回到工作台时也应刷新。

支持 Markdown 中的约定标题、资源表与决策卡 frontmatter。自定义正文可在“查看原文”中阅读；缺失字段显示尚未记录。明确的卡片依赖来自 `depends_on`，缺失、重名、循环与未关闭依赖不列为可推进。旧 `prototype` 与自定义状态保留。

单个文件上限 1 MiB；每次最多读取 400 张卡；关系图最多显示筛选后的前 40 张，完整列表仍可查看。只读所选文件夹内明确路径；不全盘扫描，不执行链接中的代码或 HTML。参考链接以文字与原文保留，当前不提供任意附件内嵌或外部材料抓取。

插件通过宿主的 Connection exact Fetch route 传输数据，沿用宿主认证和 owner 限制；相对请求兼容 Web 与 Desktop carrier。真实模型会话的 provider、模型和凭证使用宿主配置。

## 备用技能

构建时原样携带 `strategyfinder`、它依赖的 `grilling` 与可选 `learn-modeling`，以低优先级 provider 暴露；已有项目或用户安装的同名 skill 优先。这是战略功能的运行依赖，不增加本仓库公开 skill 数量，也不自动启动其他用户入口。
