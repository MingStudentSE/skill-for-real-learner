## 它做什么

`teach-core` 完整镜像 Matt Pocock 上游的 `teach` skill，并解除隐式调用限制，使 `teach-me` 能将它作为基础教学能力复用。除名称、调用属性和界面名称外，它的正文、格式文件与上游保持一致。

它建立有状态的教学工作区，以使命约束课程，维护可信资源、短课程、参考资料、术语表、学习记录、教学笔记和复用资产。

## 何时使用

通常由 [`teach-me`](teach-me.md) 自动复用。你也可以手动运行 `/teach-core`，获得不包含本仓库学习闭环补丁的原版教学体验。

| 你的处境 | 该选什么 |
| --- | --- |
| 需要原版、完整的有状态教学工作区 | `/teach-core` |
| 希望在原版教学上增加问题、概念、行动与反思闭环 | [`teach-me`](teach-me.md) |
| 只想快速学懂一个概念，不建立跨会话课程 | [`learn-one-concept`](learn-one-concept.md) |

## 有效的信号

- 每节课程都服务 `MISSION.md` 中的现实目标。
- `lessons/`、`reference/`、`GLOSSARY.md` 与 `learning-records/` 各自承担清晰、不同的职责。
- 课程使用可信来源，并通过练习和反馈增强长期保持与迁移。
- 上游更新后，除名称与调用属性外仍能逐文件对应。

## 它在流程中的位置

它是 model-invoked 基础能力，不是本仓库新增的教学阶段。`teach-me` 负责选择和应用本仓库的增量学习方法；`teach-core` 负责保持原版 `teach` 的教学工作区与课程生产契约。
