# Strategyfinder

输入 `/strategyfinder`，通过质询、实际投入与反馈分析、低成本测试，发现值得持续投入的学习方向，并决定有限资源如何分配。方向可以从实践中逐步形成；不要求先想出完整的长期答案。

## 可视化工作台

在 DeepSeek Harness 中可使用[学习工作台](strategy-plugin.md)里的“学习战略”功能，按学习空间和项目查看方向投入对照、决策依赖、关键假设、真实测试与反馈，并显式进入原生战略讨论。插件只读取工件，方向修改与决策关闭仍遵循本 skill 的用户取舍边界。

## 何时使用

| 处境 | 入口 |
| --- | --- |
| 多个长期方向需要取舍，或投入很多却不清楚回报 | `/strategyfinder` |
| 方向已明确，需要学习路线和阶段安排 | [to-plan](to-plan.md) |
| 已有学习计划，需要安排当前任务 | [to-task](to-task.md) |
| 需要讲解、练习和掌握检验 | [teach-me](teach-me.md) |

普通日计划和一次表现波动不必升级为战略问题。没有学习配置也能运行，先沿用已有工件，再按需使用默认名称。

## 怎样推进

以 `grilling` 为主干，先由你表达判断和依据，再追问目标、约束、优势与机会成本。结合真实记录，分析时间、金钱、精力去了哪里，产生哪些结果和可复用沉淀；回报也可以是与你的目标相关的非金钱收益。

对会改变取舍的关键未知，选择最小补证据动作：价值取舍继续质询，外部事实按需查证，实际效果通过低成本真实测试验证。查一个事实不必生成独立研究笔记，测试也可以是一次服务、报价、作品发布或真实工作任务。材料理解阻塞判断时才使用 [learn-modeling](learn-modeling.md)。

测试前明确投入上限、观察信号、复盘时间与停止条件，并写下预期结果和相应的投入决定。结果返回后对比预期与实际，由你决定加码、维持、缩小、转向或暂停，说明下阶段投入多少、相应减少什么。

## 记录与有效信号

长期方向与配置摘要保存在战略地图，值得跨会话跟进的问题保存在决策卡。卡记录关键假设、证据、测试安排、实际结果与取舍，小问题在对话中解决。旧卡继续保留，无需为更新格式批量迁移。

有效结果包括：

- 能解释当前投入与目标之间的关系，并指出被挤出的机会。
- 方向判断有证据，未知和长期收益仍明确标为假设。
- 测试成本可控，结果能帮助作出下一步投入决定。
- 有实际结果和明确取舍后才关闭相关问题；选择放弃也可以关闭。

产物保存在用户工作区。测试计划或演示不能替代真实效果证据；外联、发布、付费及修改真实实现按已有明确授权执行。

学习计划、任务与教学由你显式选择相应入口。新反馈在下次主动调用时回流，运行步骤见 [技能正文](../skills/learn/strategyfinder/SKILL.md)。
