## 它做什么

`strategyfinder` 帮你建立或维护唯一的长期学习战略：哪些方向值得持续投入、有限精力应如何配置、哪些高成本选择仍有关键未知。它把这些问题放进 `STRATEGY-MAP.md` 与独立的决策卡，而不是把它们写成一张待办清单。

它规划和验证战略假设，不代替日常执行。战略地图在路线清晰后交接给后续工作，但不会自动启动 SOP、任务或教学。

## 何时使用

你通过输入 `/strategyfinder` 调用它；模型不会自行调用。

| 你的处境 | 更合适的入口 |
| --- | --- |
| 多个长期方向、重大精力配置或高不可逆选择需要取舍 | `/strategyfinder` |
| 方向已经清楚，只需设计当前阶段的学习方法 | [`to-sop`](to-sop.md) |
| 已有 SOP，只需安排这一周或这一次行动 | [`to-task`](to-task.md) |
| 一段学习后的效果需要检查 | [`study-review`](study-review.md) |

短期执行波动、普通课程和单次任务不需要升级为战略问题。

## 战略地图，而不是计划表

这里的核心是**战略地图**：总图低分辨率地保存总体战略、当前阶段、护栏、复利假设和已定结论；每一张决策卡只处理一个能被证据关闭的问题。当前可推进的前沿来自未关闭且无依赖的卡，而不是地图上堆满的任务。

对重大选择，先守住“不失败底座”，再把可能的长期复利写成可被支持或推翻的假设。低成本原型、研究、访谈或前置行动都可以消除一个关键未知，但它们不会被误写成已经证实的战略。

## 常见问题

**每个学习目标都需要战略地图吗？**

不需要。只有长期方向、资源配置或重大取舍本身尚未解决时才值得建立；已明确的阶段方法和任务应留给更轻的入口。

**一次复盘结果不好，会自动改变长期战略吗？**

不会。只有反复出现、足以影响护栏、成本、资产沉淀或关键假设的新证据，才在你下一次手动调用时重新打开战略决策。

## 有效的信号

- `STRATEGY-MAP.md` 能说清总体方向、当前阶段、已定事项、未知和明确不做的事。
- 每张正在推进的卡都是一个可关闭的问题，并有对应的证据条件。
- 结论区分事实、自述、推断与未知，没有把预期收益写成既定事实。

## 它在流程中的位置

它是长期学习的战略入口。地图明确后，你可以手动进入 [`to-sop`](to-sop.md) 设计阶段方法；持续行动后的证据可由 [`study-review`](study-review.md) 发现问题，并在需要时回到战略判断。拿不准从哪开始时先用 [`ask-ming`](ask-ming.md)。
