## 它做什么

`ask-ming` 是本仓库的显式导航入口。你描述当前的学习目标、材料或卡点后，它会从现有入口中推荐最合适的一条命令，并说明该命令会读取或产出什么工件。

它推荐后就停止：不会替你启动被推荐的 skill、改写工件，或替你作出学习取舍。这使它成为导航器，而不是隐形工作流。

## 何时使用

你通过输入 `/ask-ming` 调用它；模型不会自行调用。

| 你的处境 | 它通常会指向 |
| --- | --- |
| 长期方向或精力取舍不清楚 | [`strategyfinder`](strategyfinder.md) |
| 学习使命或当前决定说不清 | [`grill-with-learn`](grill-with-learn.md) |
| 已有方向或 SOP，需要继续推进 | [`to-sop`](to-sop.md) 或 [`to-task`](to-task.md) |
| 想把材料、章节或概念整理成模型笔记 | [`learn-modeling`](learn-modeling.md) |
| 想互动学一个概念、开展持续教学或复盘 | 对应的专门入口 |

已有明确选择时，直接调用那个 skill 更快。

## 它给出的不是路线图，而是一条下一步

`ask-ming` 的核心是**显式入口**：默认只给一条主命令；只有存在重要取舍时，才附一个备选。推荐应同时说明为什么此刻匹配、会接触哪些工件，以及你接下来需要亲自输入什么。

## 常见问题

**它会自动把我带到下一阶段吗？**

不会。它只给建议。学习者决定是否执行、何时执行，以及是否带着现有工件开启新会话。

**为什么不直接看 README？**

README 展示全貌；这个入口根据你当前的阻塞点和已有工件缩小到一个可执行选择。

## 有效的信号

- 结果中有一条明确的 `/skill` 命令，而不是泛泛的流程说明。
- 推荐理由对应你的实际卡点，并说清会用到或生成的工件。
- 它没有开始执行所推荐的工作。

## 它在流程中的位置

这是覆盖整个工具集的独立导航器，不是链条上的一个阶段。它常把你送往 [`strategyfinder`](strategyfinder.md)、[`grill-with-learn`](grill-with-learn.md) 或一个已有工件的后续入口；完整入口清单见[文档索引](README.md)。
