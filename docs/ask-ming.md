# ask-ming · 学习工具使用指南

第一次用这套工具，可以问 `/ask-ming 这些 skill 分别能帮我做什么？`。也可以直接带上卡点，例如 `/ask-ming 我读完了一章，想知道自己能不能独立用出来，该选哪个？`。

## 按你想得到的结果选

| 你想做什么 | 可以选择的入口 |
| --- | --- |
| 比较几个长期方向，看看精力值得投在哪里 | [strategyfinder](strategyfinder.md) 从已有投入和反馈出发，设计低成本测试，用结果决定取舍。 |
| 已有学习意图，想商量适合自己时间和基础的路线 | [to-plan](to-plan.md) 和你讨论目标、练习与检验点，同意方案后再写计划。 |
| 已经定好计划，想知道本周具体做什么 | [to-task](to-task.md) 把计划拆成有产出和验收条件的编号任务。对话中已明确的计划也可以用。 |
| 想学懂概念、试一道题或检验自己能否独立应用 | [teach-me](teach-me.md) 给你讲解、练习与反馈，也可用 `/teach-me 01` 继续当前项目的第 01 项任务。 |
| 想把指定章节整理清楚，之后能回到原文 | [learn-modeling](learn-modeling.md) 整理概念、关系与出处，留下可以复用的模型笔记。 |
| 有个想法或决定，想请人追问其中的假设 | [grill-me](grill-me.md) 显式开始一轮质询，逐步澄清决定和取舍。 |
| 想澄清学习决定，但指定材料中的概念可能影响判断 | [grill-with-learn](grill-with-learn.md) 在质询遇到材料障碍时按需建模，再回来讨论原问题。 |
| 想在当前讨论中使用分轮追问的方法 | [grilling](grilling.md) 提供访谈方法，可以直接点名，也可供其他入口复用。 |

在上面的读书例子里，如果目标是检验自己能否应用，可以输入 `/teach-me 用一个新例子检验我对这一章的理解`。如果想先弄清几个概念在原文中的关系，可以选择 `/learn-modeling` 并附上章节。一个得到练习反馈，一个留下材料笔记，选择取决于你现在想得到什么。

`ask-ming` 在对话里解释各入口的用途和用法，下一步由你自行选择并发起，也可以继续询问或停在这里。导航过程不自动调用其他入口或改写学习文件。已知道自己要用什么时，可以直接启动相应入口。
