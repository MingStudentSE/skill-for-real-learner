## 它做什么

`teach-me` 围绕一个真实问题开展有状态、跨会话的教学，并维护课程工件与 `LEARNER-PROFILE.md`。它调用完整镜像上游 `teach` 的 `teach-core`，再增加“问题 → 概念 → 行动 → 反思”学习闭环，并用每节课的明确目标控制停止。

它不是一次性的知识问答：每轮都应形成或更新课程工件，并让学习者以讲回、判断、迁移或微实验展示当前理解。

## 何时使用

你通过输入 `/teach-me <能力、概念或真实问题>` 调用它；模型不会自行调用。

| 你的处境 | 该选什么 |
| --- | --- |
| 一个真实问题需要连续多轮教学、练习和反馈 | `/teach-me` |
| 只想快速学懂一个概念 | [`learn-one-concept`](learn-one-concept.md) |
| 指定材料还没有可用的结构 | [`learn-modeling`](learn-modeling.md) |
| 想先检验当前掌握，或已积累表现证据需要检查效果 | [`study-review`](study-review.md) |

## 前提条件

`teach-core` 在当前学习工作区中维护 `MISSION.md`、`RESOURCES.md`、`lessons/`、`reference/`、`GLOSSARY.md`、`learning-records/`、`NOTES.md` 与需要的 `assets/`。`teach-me` 另外维护当前领域的 `LEARNER-PROFILE.md`。开始前带上真实问题或已有学习工件；使命发生实质变化时需要先确认。

## 学习闭环

它的核心是**闭环**：从下一步真实行动倒推最小必要知识，解释关键概念及其边界，在可能影响行动的地方暂停，再用学习者自己的展示和低成本实验获得反馈。结果用于修正下一步，不用“课程完成”宣布掌握。

每节课开始前都会展示一条可检查的**本课目标**：你要在什么情境下、不看材料完成哪一种解释、判断或迁移，以及什么表现算达标。目标同时包含用自己的话重建核心关系，以及一次与当前真实问题相关的最小展示。

达到本课目标后，当前学习块立即结束，只总结证据、边界和唯一下一步；新学习块等你明确要求后再开始。同一核心误区经过两轮反馈与重试仍不稳定时，当前学习块也会结束，并把该项标为待复习，下一次更换解释或练习。

## 学习画像与最佳学习区间

`teach-me` 不套用固定难度，而是把目标依赖的知识分支分为三个区域：

- **已经掌握的区域**：有独立表现证据的内容默认跳过，避免低增量重复。
- **跨越前置知识的区域**：学习者只能记结论、猜答案或模仿时，退回补足最小前置桥梁。
- **合适的学习区域**：学习者尚不会，但能凭已有知识经过努力推导、解释或应用。下一个最小学习块放在这里。

它先复用学习记录、复盘、作品和当前对话中的证据，只在有决策性缺口时逐个探测。每次讲回、判断或应用都可能让理解边缘前移或退回，新证据一旦改变教学决策，就更新 `LEARNER-PROFILE.md`。

画像只是当前学习使命下的教学决定视图，不是对人的永久级别。它只保留会改变下一节课的活跃分支；持久理解与误解修正仍保存在 `learning-records/`，稳定教学偏好仍保存在 `NOTES.md`。

若课程确实需要指定材料的结构，教学过程可以复用 [`learn-modeling`](learn-modeling.md)，但学习模型本身不是课程、练习或能力证据。

## 常见问题

**它和 `learn-one-concept` 有什么不同？**

`teach-me` 维护跨会话课程和工作区工件；后者是一个轻量、单概念的学习回合。

**它和 `teach-core` 有什么不同？**

`teach-core` 保持原版 `teach` 的完整行为；`teach-me` 是学习者显式选择的包装器，只增加本仓库的学习闭环与证据判断。

**课程结束就说明我掌握了吗？**

不说明。只有独立表现或真实迁移才能支持能力结论；不足的地方会留下明确的下一步。

**它会一直追问下去吗？**

不会。每节课都以开课前明确的本课目标为停止标准；达标即结束，两轮重试仍不稳定也结束并转为待复习。

## 有效的信号

- 当前问题被收窄为能推动行动的最小学习块。
- 每节课都有可检查的本课目标，达标后当前学习块立即结束。
- `LEARNER-PROFILE.md` 能用表现证据说明已验证起点、前置断层与当前理解边缘。
- 每轮都有课程工件，以及学习者自己的讲回、判断、迁移或实验结果。
- 下一步位于“尚不会，但经过努力可以理解”的区域，并由观察到的结果持续调整。

## 它在流程中的位置

它是持续教学的执行入口，可读取 [`to-sop`](to-sop.md) 和 [`to-task`](to-task.md) 的前序工件，但不会由它们自动启动。课程积累出有意义的检查点后，学习者可手动运行 [`study-review`](study-review.md)。
