## 它做什么

`teach-me` 围绕一个真实问题开展有状态、跨会话的教学，并维护课程工件。它把上游 `teach` 的课程、练习和反馈能力放进“问题 → 概念 → 行动 → 反思”的学习闭环。

它不是一次性的知识问答：每轮都应形成或更新课程工件，并让学习者以讲回、判断、迁移或微实验展示当前理解。

## 何时使用

你通过输入 `/teach-me <能力、概念或真实问题>` 调用它；模型不会自行调用。

| 你的处境 | 该选什么 |
| --- | --- |
| 一个真实问题需要连续多轮教学、练习和反馈 | `/teach-me` |
| 只想快速学懂一个概念 | [`learn-one-concept`](learn-one-concept.md) |
| 指定材料还没有可用的结构 | [`learn-modeling`](learn-modeling.md) |
| 已积累一段时间的表现证据，需要检查效果 | [`study-review`](study-review.md) |

## 前提条件

它在当前学习工作区中工作，并维护 `MISSION.md`、`RESOURCES.md`、`lessons/`、`reference/`、`learning-records/` 与需要的 `assets/`。开始前带上真实问题或已有学习工件；使命发生实质变化时需要先确认。

## 学习闭环

它的核心是**闭环**：从下一步真实行动倒推最小必要知识，解释关键概念及其边界，在可能影响行动的地方暂停，再用学习者自己的展示和低成本实验获得反馈。结果用于修正下一步，不用“课程完成”宣布掌握。

若课程确实需要指定材料的结构，教学过程可以复用 [`learn-modeling`](learn-modeling.md)，但学习模型本身不是课程、练习或能力证据。

## 常见问题

**它和 `learn-one-concept` 有什么不同？**

`teach-me` 维护跨会话课程和工作区工件；后者是一个轻量、单概念的学习回合。

**课程结束就说明我掌握了吗？**

不说明。只有独立表现或真实迁移才能支持能力结论；不足的地方会留下明确的下一步。

## 有效的信号

- 当前问题被收窄为能推动行动的最小学习块。
- 每轮都有课程工件，以及学习者自己的讲回、判断、迁移或实验结果。
- 下一步由观察到的结果决定，而非由固定课程目录决定。

## 它在流程中的位置

它是持续教学的执行入口，可读取 [`to-sop`](to-sop.md) 和 [`to-task`](to-task.md) 的前序工件，但不会由它们自动启动。课程积累出有意义的检查点后，学习者可手动运行 [`study-review`](study-review.md)。
