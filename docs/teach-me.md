## 它做什么

`teach-me` 围绕一个真实问题开展有状态、跨会话的教学，并维护课程工件与 `LEARNER-PROFILE.md`。它读取随入口内置、逐字保留的官方 `teach` 正文，再增加“问题 → 概念 → 机制 → 判断 → 实践反馈”学习闭环，并用每节课的明确目标控制停止。

它不是一次性的知识问答：每轮都应形成或更新课程工件，并让学习者以讲回、判断、迁移或微实验展示当前理解。

## 何时使用

你通过输入 `/teach-me 01` 或 `/teach-me <能力、概念或真实问题>` 调用它；模型不会自行调用。

| 你的处境 | 该选什么 |
| --- | --- |
| 一个真实问题需要连续多轮教学、练习和反馈 | `/teach-me` |
| 只想学懂一个概念并练一次 | `/teach-me`，明确限定为一个学习块 |
| 指定材料还没有可用的结构 | [`learn-modeling`](learn-modeling.md) |
| 想先检验当前掌握或检查已有表现 | `/teach-me`，明确要求先做一次掌握检验 |

## 前提条件

`teach-me` 在当前学习项目中维护 `MISSION.md`、`RESOURCES.md`、`lessons/`、`reference/`、`GLOSSARY.md`、`learning-records/`、`NOTES.md` 与需要的 `assets/`。`teach-me` 另外维护当前领域的 `LEARNER-PROFILE.md`。开始前带上真实问题或已有学习工件；使命发生实质变化时需要先确认。若已有 `docs/agents/learning.md`，先按它解析用户的命名与布局；没有配置也可直接教学。内部官方正文提到的 `/teach` 工作区就是本次 `/teach-me` 的当前项目；教学状态相对当前项目，格式链接相对内部参考文件。

课程用到 `reference/` 里的本地电子书时，对应课节会把来源说明或阅读任务直接链接到实际使用的 PDF 页码，而不是只打开整本书。

## 按编号开始任务

在当前项目输入 `/teach-me 01`，会定位 `tasks/01-标题.md`，读取关联计划、依赖和既有证据，从尚未完成的部分教学。根 `AGENTS.md` 的配置可以分别指定 workspace 和 project 路径，也可以映射任务、课程和记录目录。已有布局继续使用。

在工作空间根目录且多个项目均有 01 时，先询问项目；编号不存在或重复时也会询问，不猜选、不自动创建替代任务。编号必须完整匹配，01 不会匹配 010。

每个任务可以分多节课完成。课后先记录实际表现与证据，再回链当前任务，逐项说明已满足与未满足的验收并更新状态。只有全部任务验收得到充分证据时才标记已完成；单节课达标不会自动标完任务，也不会自动开始下一编号。独立教学仍可直接使用，无需先建立计划或任务。

## 学习闭环

它的核心是**闭环**：从下一步真实行动倒推最小必要知识，解释关键概念及其边界，在可能影响行动的地方暂停，再用学习者自己的展示和低成本实验获得反馈。结果用于修正下一步，不用“课程完成”宣布掌握。选材按缺少它是否会阻碍目标来判断，必要内容较多时拆课并保留依赖；成熟领域优先借助可靠框架，再在自己的问题中内化。

每节课开始前都会展示一条可检查的**本课目标**：你要在什么情境下、不看材料完成哪一种解释、判断或迁移，以及什么表现算达标。目标同时包含用自己的话重建核心关系，以及一次与当前真实问题相关的最小展示。判断包括说明为什么适用，也允许有理由地暂不采用：需要说清不满足的条件，以及什么新证据会改变判断。

达到本课目标后，当前学习块立即结束，只总结证据、边界和唯一下一步；新学习块等你明确要求后再开始。同一核心误区经过两轮反馈与重试仍不稳定时，当前学习块也会结束，并把该项标为待复习，下一次更换解释或练习。练习按目标选择检索、辨析、解释或迁移，并及时反馈；实践技能可先看包含必要知识和关键理由的小示范、尝试相近任务，再针对卡点解释。

对值得长期使用的知识，学习记录会按需保留下次调用的情境和反馈信号。后续遇到相关问题时，再通过检索和迁移观察是否保持、是否适用；当堂达标与长期掌握分别记录。临时知识按未来用途决定是否复习。

## 学习画像与最佳学习区间

`teach-me` 不套用固定难度，而是把目标依赖的知识分支分为三个区域：

- **已经掌握的区域**：有独立表现证据的内容默认跳过，避免低增量重复。
- **跨越前置知识的区域**：学习者只能记结论、猜答案或模仿时，退回补足最小前置桥梁。
- **合适的学习区域**：学习者尚不会，但能凭已有知识经过努力推导、解释或应用。下一个最小学习块放在这里。

它先复用学习记录、复盘、作品和当前对话中的证据，只在有决策性缺口时逐个探测。每次讲回、判断或应用都可能让理解边缘前移或退回，新证据一旦改变教学决策，就更新 `LEARNER-PROFILE.md`。

画像只是当前学习使命下的教学决定视图，不是对人的永久级别。它只保留会改变下一节课的活跃分支；持久理解与误解修正仍保存在 `learning-records/`，稳定教学偏好仍保存在 `NOTES.md`。

若课程确实需要指定材料的结构，教学过程可以复用 [`learn-modeling`](learn-modeling.md)，但学习模型本身不是课程、练习或能力证据。

## 常见问题

**只想学一个概念也可以用吗？**

可以，明确要求只推进一个最小学习块即可。仍以本课目标和独立表现控制停止，并保留需要的课程与学习证据。

**官方教学能力从哪里来？**

官方 `teach` 正文与四份格式文件保存在入口内部的 `references/teach/`，由外层直接读取。来源提交保留在外层入口，官方五份原文独立保持原样。

**课程结束就说明我掌握了吗？**

不说明。只有独立表现或真实迁移才能支持能力结论；不足的地方会留下明确的下一步。

**它会一直追问下去吗？**

不会。每节课都以开课前明确的本课目标为停止标准；达标即结束，两轮重试仍不稳定也结束并转为待复习。

## 有效的信号

- 当前问题被收窄为能推动行动的最小学习块。
- 每节课都有可检查的本课目标，达标后当前学习块立即结束。
- `LEARNER-PROFILE.md` 能用表现证据说明已验证起点、前置断层与当前理解边缘。
- 每轮都有课程工件，以及学习者自己的讲回、判断、迁移或实验结果。
- 课程使用本地电子书时，来源链接能直接打开支撑当前内容的 PDF 具体页。
- 下一步位于“尚不会，但经过努力可以理解”的区域，并由观察到的结果持续调整。

## 它在流程中的位置

它是持续教学的执行入口，读取已有 当前项目的 `LEARNING-PLAN.md` 与 `tasks/` 下对应编号任务的目标、依赖和验收要求，并将课程证据、待复习项与唯一下一步链接回去。没有计划也能直接教学；不要求战略或 SOP 前置工件。计划修订建议交给学习者下次显式运行 `/to-plan`，任务拆分或重排交给 `/to-task`。课程积累出检查点后，可在 `/teach-me` 中明确要求按已有表现检验掌握并回看结果。需要整理本地布局与阅读规则时，可手动运行 [`setup-learn-skills`](setup-learn-skills.md)。
