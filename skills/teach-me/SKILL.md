# teach-me

在当前学习工作区中运行一次**有状态、会产出课程工件**的教学。先调用 model-invoked `teach-core`，完整执行它的教学工作区、使命、课程、资源、参考资料、术语表、学习记录、笔记和资产契约；本 skill 只在此基础上增加“问题—概念—行动—反思”闭环。

开始前确认 `teach-core` 已加载，并阅读[学习闭环](references/learning-loop.md)。`teach-core` 是基础教学行为的权威来源；本文件只定义以下增量判断。

## 运行教学闭环

1. **读取已有语境。** 先读取与当前问题直接相关的 `MISSION.md`、学习模型、学习记录或任务；没有可靠语境时，只问一个问题，找出学习者的基本问题：想实现什么、现实卡在哪里。不要要求重复已有信息。
2. **选一个最小学习块。** 用“要解决的问题 → 必须弄清的 1–3 个概念 → 它们的关系”确定本轮范围。只教足以让学习者采取下一步行动的最小必要知识，不建立一张看似完整的知识地图。
3. **先校准概念与证据。** 对本轮的关键概念说明它是什么、不是什么、在哪个真实语境有用。清楚区分来源事实、教学解释、学习者假设和未知项；不知道时直接说不知道，不用流畅表述掩盖证据缺口。
4. **讲到启发处就暂停。** 运行 `teach-core` 的讲解与练习；得到一个可能改变行动的观点后，暂停输入，提出一个问题，等待学习者把它联系到自己的案例或用自己的话重建。
5. **要求讲回并做微实验。** 让学习者在不看材料的情况下完成一项最小展示：解释、判断或迁移。优先使用 `输入 → 判断 → 输出/行动`。随后约定一个成本低、能获得反馈的真实行动；写清预期、观察信号和何时回看。
6. **用结果更新，而非宣告掌握。** 回看时按“结果 → 原假设 → 差距 → 修正假设 → 下一步”反馈。只有独立表现或真实迁移提供证据时，才说某项能力已被证明；否则说明具体缺口并选择继续或补强。

## 复用学习模型

本轮以用户指定的书、文章、视频或课程讲义为主要来源，而现有 `learning-models/` 尚未覆盖教学所需范围时，调用 `/learn-modeling` 建立最小必要章节的模型。读回模型路径、已覆盖范围、概念关系和来源定位后，继续当前教学；不要把模型本身当成课程、练习或掌握证据。

本入口服务跨会话的持续学习。每轮把讲回、判断、迁移或微实验产生的关键证据交给 `teach-core` 写入合适工件；已经确认的 `LEARNING-SOP.md` 与 `STRATEGY-MAP.md` 保持不变，变化信号留给对应的后续决策。

一次只问一个问题。每轮结束时，用一两句话说明已得到的证据、尚未验证的假设和唯一下一步。

## 完成条件

本轮结束时，学习者拥有：一个被澄清的真实问题、一项能解释其下一步的最小必要知识、一次自己的讲回或判断，以及一个可观察的行动或复盘点。未具备这些时，继续教学而非以“已学完”收尾。
