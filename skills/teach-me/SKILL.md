# teach-me

在当前学习工作区中运行一次**有状态、会产出课程工件**的教学。先调用 model-invoked `teach-core`，完整执行它的教学工作区、使命、课程、资源、参考资料、术语表、学习记录、笔记和资产契约；本 skill 只在此基础上增加“问题—概念—行动—反思”闭环。

开始前确认 `teach-core` 已加载，并阅读[学习闭环](references/learning-loop.md)。只在首次创建学习画像，或新证据改变画像中的教学决定时，阅读[学习画像格式](references/LEARNER-PROFILE-FORMAT.md)并写入。`teach-core` 是基础教学行为的权威来源；本文件只定义以下增量步骤。

## 运行教学闭环

1. **恢复当前语境。** 读取与当前问题直接相关的 `MISSION.md`、`LEARNER-PROFILE.md`、学习模型、学习记录、复盘或任务，只补问现有工件未提供的决定性信息。**本步完成：** 已明确本轮真实问题、当前表现、现有证据与待验证项；缺少其中一项时，只问一个问题并等待。
2. **校准理解边缘。** 只列出会改变下一节课的活跃知识分支，按学习闭环的**三区判断**与探测规则处理。**本步完成：** 每个活跃分支都有教学决定；还有决定性缺口时，只问一个区分性问题并等待，将回答分类后才进入下一步。
3. **选定最小学习块并立本课目标。** 用“真实问题 → 必须弄清的 1–3 个概念 → 关系”确定本轮范围，让表现证据决定顺序。教学前写出并向学习者展示一条可检查的**本课目标**：学习者要在什么情境下、不看材料完成哪一种解释、判断或迁移，以及什么表现算达标。本课目标同时要求学习者用自己的话重建本块核心关系，并完成一次与当前真实问题相关的最小展示；把它写入本节课程工件。**本步完成：** 只有一个下一学习块；本课目标及其达标证据已明确；为什么现在可学、预期的有效努力与退回补桥信号均已写清。
4. **教一个推理步骤后暂停。** 运行 `teach-core` 的讲解与练习；对关键概念说明定义、边界、当前语境和证据类型。让困难集中在知识或技能本身。一个观点可能改变行动时，提出一个问题并等待学习者联系自己的案例或重建这个观点。**本步完成：** 学习者给出自己的连接或重建后，立即进入第 5 步的本课目标展示。
5. **用本课目标停止。** 先判断第 4 步的无提示表现是否已覆盖本课目标，只对缺少的达标证据再做一次最小展示，并按学习闭环校准理解边缘。**停止线：** 本课目标达标时，立即结束当前学习块，只总结达标证据、证据边界和唯一下一步，等待学习者明确要求后再开始新的学习块。次要表述修正记入反馈，不扩张本课目标。同一核心误区最多进行两轮“反馈 → 重试”；两轮后仍不稳定时，标为待复习并结束当前学习块，下次更换解释或练习。把一个成本低、能获得反馈的真实行动记为唯一下一步；本课目标本身已完成迁移时，直接记录该结果。**本步完成：** 当前学习块已达标或已转为待复习，且状态、表现证据、证据边界和唯一下一步均已记录。
6. **更新画像与下一步。** 首次校准完成后创建 `LEARNER-PROFILE.md`；新证据改变教学决定时，按格式就地更新并裁剪画像。持久理解、误解修正或先验知识另写入 `learning-records/`。回看时按“结果 → 原假设 → 差距 → 修正假设 → 下一步”反馈。**本步完成：** 画像与最新证据一致，且只留下一个下一步。

## 复用学习模型

本轮以用户指定的书、文章、视频或课程讲义为主要来源，而现有 `learning-models/` 尚未覆盖教学所需范围时，调用 `/learn-modeling` 建立最小必要章节的模型。读回模型路径、已覆盖范围、概念关系和来源定位后继续教学；把模型作为教学输入，用学习者的独立表现另行产生掌握证据。

本入口服务跨会话的持续学习。`LEARNER-PROFILE.md` 只保存当前教学决定；`learning-records/` 保留持久证据，`NOTES.md` 保留稳定教学偏好。画像通过链接引用两者。已经确认的 `LEARNING-SOP.md` 与 `STRATEGY-MAP.md` 保持不变，变化信号留给对应的后续决策。

一次只问一个问题。每轮结束时，用一两句话说明已得到的证据、尚未验证的假设和唯一下一步。

## 完成条件

本轮以第 5 步停止线为完成条件。结束时，学习者拥有：一个被澄清的真实问题、一份已创建或确认仍有效的学习画像、一条明确的本课目标、该目标已达标或转为待复习的表现证据，以及一个已记录的可观察下一步。
