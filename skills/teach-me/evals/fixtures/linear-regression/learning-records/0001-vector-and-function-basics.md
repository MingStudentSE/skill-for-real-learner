# Vector and function basics are established

The learner independently calculated vector addition and scalar multiplication, then explained the difference between a function's input, output, and adjustable parameter. This allows future lessons to skip those definitions while not assuming any knowledge of derivatives or gradients.

## Evidence

An unaided calculation and explanation using a new function example.

## Implications

Use functions as the starting point for probing local change; do not reteach vector arithmetic unless later evidence conflicts.
