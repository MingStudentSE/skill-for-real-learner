# 学习画像格式

`LEARNER-PROFILE.md` 位于当前学习工作区根目录。`teach-me` 在首次校准完成后创建它，并在新证据改变教学决定时就地更新。画像是当前学习使命下的**教学决定视图**：它让下一节课能直接恢复活跃知识分支、证据状态和理解边缘。

## 单一事实源

- `MISSION.md` 定义学习使命；画像链接它，另行写明本轮校准的可观察目标。
- `learning-records/` 保存持久理解、误解修正和先验知识；画像摘要当前教学含义并链接证据。
- `NOTES.md` 保存稳定教学偏好；画像只链接。

## 状态与教学决定

三区判断的定义与移动规则以[学习闭环](learning-loop.md#0-用三区判断定位理解边缘)为唯一权威来源。画像只记录以下操作状态：

| 证据状态 | 当前教学决定 |
| --- | --- |
| 已验证 | 跳过已满足当前目标的内容 |
| 发展中 | 在理解边缘教一个最小学习块 |
| 前置断层 | 先补当前需要的最小前置桥梁 |
| 待探测 | 先做一个能改变教学决定的区分性检验 |

每个“已验证”都指向实际表现，并说明尚未覆盖的范围。

## 更新与裁剪

1. 首次校准后创建画像；在学习者回答区分性问题前，保持相关分支为“待探测”。
2. 新证据改变分支状态、当前教学决定或理解边缘时，立即更新对应行与下一步。
3. 一次表现只支持它实际覆盖的范围。证据过时、与新表现冲突或仅有提示后完成时，将分支标为“发展中”或“待探测”。
4. 只保留会改变当前课程选择的活跃分支。一个分支不再影响下一步时，从理解地图移除；其持久证据留在 `learning-records/`。
5. 每次写入后确认：每行都有证据或待验证假设，每行都会改变教学决定，全文只有一个下一步。

## 模板

```md
# 学习画像

- **学习使命：** [[MISSION.md]]
- **本轮校准目标：** <本轮要观察的解释、判断或行动>
- **最近校准：** <YYYY-MM-DD；本次使用的表现或证据>

## 理解地图

| 活跃知识分支 | 证据状态 | 证据与边界 | 当前教学决定 |
| --- | --- | --- | --- |
| <会改变下一节课的概念、关系或技能> | 已验证｜发展中｜前置断层｜待探测 | <实际表现或假设、来源链接与未覆盖范围> | 跳过｜在理解边缘教学｜先补桥｜先探测 |

## 当前理解边缘

- **当前决定：** 先探测｜先补桥｜在理解边缘学习
- **下一步：** <唯一的探测、前置桥梁或最小学习块>
- **为什么现在做：** <已有证据如何支撑这个决定>
- **预期的有效努力：** <学习者需要推导、解释或应用什么>
- **重新校准信号：** <什么表现使理解边缘前移或转为补桥>

## 待验证假设

- <影响下一步但尚无足够证据的判断；无则写“无”>

## 相关状态

- **持久理解与修正：** <相关 `learning-records/` 链接；无则写“尚无”>
- **教学偏好：** <`NOTES.md` 链接；无则写“尚无稳定记录”>
```
