# 学习效果审查依据

本文件把会改变复盘结论的概念、因果和边界翻译成 `study-review` 的审查动作。先读“判断依据”，再按“审查时怎样用”执行；不要把这里的执行规则说成唯一结论或既有事实。

## 1. 学习效果是：行动所依据的假设被事实校正

**判断依据。** 学习是更新假设的过程：人总是在自己对事物的解释下作出判断和决策；假设与事实越贴近，判断越可能改善。知识量增加本身不必然产生更深的思考，因为旧假设可以原封不动地支配新输入。

**审查时怎样用。** 不审查“这门课看完了吗”，而审查一条变化主张：

```text
过去在什么情境下做什么判断／行动
  → 当时依据的假设是什么
  → 本轮学到的概念、关系或方法改变了哪个假设
  → 在同类或相近情境下，判断／行动和结果有什么可观察变化
```

先把旧判断、旧行动和实际结果写成事实，再写“原来以为……所以……”。没有旧假设或结果时，只能说本轮有待验证，不能声称学习已经有效。

**不能推出什么。** 结果不如预期不等于学习者没有学习，也不自动说明课程无效；工具、时间、环境、目标本身或偶然因素都可能参与结果。复盘的工作是缩小哪些假设仍可疑，而不是替任何一方判责。

## 2. 反思是追查原因并校正假设，不是对结果打分

**判断依据。** 做事是带着假设行动，然后出现结果；反思从已经出现的现象倒推当时的假设，检查它是否足以解释结果，并调整它。总结结果好坏不同于反思结果为何出现。未经核验的直觉或惯例容易被当成事实，从而重复同一种错误处理方式。

**审查时怎样用。** 每一个非“待验证”的结论都按下面的顺序写：

1. **结果／表现事实：** 实际完成了什么、说了什么、提交物是什么、外部反馈是什么。事实不要掺入“很差”“已经懂了”这类解释。
2. **原假设：** 当初为什么认为这份材料、练习或方法会带来预期变化；必要时区分学习者的概念假设、课程的内容假设、SOP 的方法假设和任务的练习假设。
3. **差距：** 哪个预期没有出现；是概念说不清、边界判断错、关系断裂，还是在真实约束下无法行动。
4. **修正假设：** 用目前事实能支持的最小解释替换旧解释；多个解释仍可能时并列保留，不假装已经找到根因。
5. **下一步检验：** 设计一个成本更低、能区分这些解释的展示、判断或真实任务。

**不能推出什么。** 一段流畅复盘也只是新的解释；没有新的表现或结果检验时，它仍是学习者假设。不要把“能说出原因”直接登记为“能力已证明”。

## 3. 要找的是知识阻塞和最小必要知识，不是补更多内容

**判断依据。** 真正拖慢后续判断的，往往不是少学了一个技巧，而是一个重要概念没有弄清、与已有知识没有接上，形成“自以为知道”的知识阻塞。应把慢功夫放在真实且重要的问题上：先锁定一个核心问题，再找直接相关的基本概念，并分析这些概念如何共同解释或解决问题。

**审查时怎样用。** 当表现没有达到预期时，先定位本轮的最小阻塞点：

| 观察到的差距 | 优先核查的知识阻塞 |
| --- | --- |
| 能背术语，换一个说法就答错 | 定义或关键字义没有厘清 |
| 知道单个概念，却无法说明为什么这样选 | 概念之间的因果、前提或对比关系缺失 |
| 熟悉例题，遇到相近条件就误用 | 适用条件、边界或反例没有学清 |
| 解释正确，真实行动仍推进不了 | 前置技能、工具约束、环境条件或任务设计，而非再加定义 |

只要能定位其中一项，就先修它并重新检验。不要因为一次失败就把下一轮扩展成整套材料、整套课程或大量重复练习。

**不能推出什么。** “最小”不是随意删减，更不是只留一个好记的口号；缺少决定判断的前提、关系或条件时，最小内容仍然不足。

## 4. 概念必须有清晰含义、边界和证据层级

**判断依据。** 同一个词在不同语境可能指向不同对象，不厘清词义就容易在讨论和判断中偷换概念。对知识诚实要求承认不懂、知道概念的适用边界，并把个人重新定义放在已有定义和实践检验之后。个人定义可以服务自己的问题，但不能替代通用定义或被伪装成事实。

**审查时怎样用。** 审查概念相关表现时，逐项分开记录：

- **来源事实：** 材料、代码、数据或领域资料实际说了什么；
- **教学解释：** 为了理解而补的类比、简化或推导；
- **学习者工作定义：** 学习者如何把概念接到当前问题；
- **未知：** 当前材料或表现无法回答的条件、范围或反例。

若学习者的判断失败，先问“他把哪个词、条件或关系当成了什么”，再决定是否修材料模型。若通用定义正确而个人工作定义不适配情境，修的是应用假设；若来源本身不足以说明边界，补的是可靠资料，不能用更流畅的解释填空。

**不能推出什么。** 学习者能给出一个贴近自己的原创表述，不等于专业定义被改写；反过来，能背通用定义也不等于能够在自己的情境中判断。

## 5. 输入必须停在能改变判断或行动的地方

**判断依据。** 输入不应在接收信息处结束。遇到有启发的观点后，先暂停扩展输入，转向追问它解释什么、与已有经验有什么关系、能否用于下一步。记录的目的不是收集他人的观点，而是借助概念和模型调整自己的思考与行动路径。

**审查时怎样用。** 将材料完成、摘录数量和笔记数量只当作背景。检查学习者是否曾把本轮知识接到一个具体问题：

1. 它解释了哪个真实或相近的现象？
2. 它改变了哪个判断、选择或行动方案？
3. 这个变化留下了什么表现、产物或反馈？

三个问题都没有答案时，优先安排一次小判断或微行动，而不是继续输入。已经能回答前两个问题、尚未发生真实行动时，最多可记为“理解或判断证据”，不能升级为行动效果。

**不能推出什么。** “把它联系到生活”不能靠代入一个漂亮故事完成；学习者没有提供场景时，应写“场景待补”或给出构造情境进行判断检验，不得虚构他的经历。

## 6. 讲回、刻意练习与反馈的作用，是制造和校正证据

**判断依据。** 讲回不只是输出：为了讲清楚，人会暴露原先以为懂、实际仍堵住的部分；说明和分享也会迫使人检查知识是否站得住。练习的重点不是增加次数，而是通过有针对性的训练改变思考过程，并以反馈修正表现。

**审查时怎样用。** 把下列展示看成不同类型的证据，并写明它们各自能证明什么：

| 展示 | 可以支持的结论 | 仍不能证明的部分 |
| --- | --- | --- |
| 不看材料讲回定义、边界与关系 | 能否重建当前理解；哪里出现知识阻塞 | 是否能在真实约束下行动 |
| 给定新输入后说明判断及理由 | 是否识别适用条件，能否迁移到相近情境 | 能否稳定处理完整真实任务 |
| 独立完成真实任务并得到反馈 | 本轮知识是否参与了实际判断／行动及其结果 | 是否已在所有情境稳定掌握 |

这不是现成的正式“证据等级表”，而是 `study-review` 为落实“讲回暴露阻塞、练习需要反馈、行动检验知识”形成的执行推断。作出“有效”“部分有效”或“未产生预期效果”结论时，必须对应到表中真实出现的展示，不能只用课程完成或自我感受。

**不能推出什么。** 一次正确回答、一次成功行动都可能是偶然、提示帮助或环境优势。只有跨情境的独立表现才能逐步增强结论；证据不足时保留“待验证”。

## 将证据送回正确位置

只有完成前六节的“事实 → 假设 → 差距”之后，才决定更新哪里：

| 已定位的问题 | 应校正的位置 | 下一步的最小检验 |
| --- | --- | --- |
| 来源不足、定义／边界／关系有误，或最小必要知识选错 | `learning-models/`、课程或参考资料 | 用修正后的概念解释一个旧案例，并做一个新判断 |
| 输入、练习、反馈、资源或节奏不适合当前学习者 | `LEARNING-SOP.md` | 保持目标能力不变，只改变一个学习方法变量后比较表现 |
| 任务难度、顺序、场景或反馈来源不能暴露差距 | `TASKS.md` | 设计一项能暴露该差距的讲回、判断或真实任务 |
| 缺少独立表现、外部反馈或可观察结果 | 不修改结论，先补收证据 | 明确下一项展示及其完成条件 |
| 工具、时间、环境等约束改变了结果 | 任务约束或执行条件 | 在记录约束后重做可比的最小尝试 |

内容、SOP 与任务的任何更新都是下一轮要检验的新假设；它不能倒过来证明上一轮已经产生学习效果。
