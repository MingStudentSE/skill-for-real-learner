# 学习效果审查依据

本文件提供 `study-review` 判读证据、限定结论和定位学习设计问题时使用的参考标准。执行顺序与完成条件以 `SKILL.md` 为准。

## 1. 区分当前达到与学习变化

学习会校正行动所依据的假设。要判断“学习产生了变化”，证据链需要同时覆盖：

```text
过去的情境、判断或行动
  → 当时所依据的假设
  → 本轮关键知识校正了什么
  → 相同或相近情境中的新表现与结果
```

只有当前独立表现时，可以判断学习者目前是否达到明确目标；结论范围停在当前能力。具备前后状态时，才进一步判断发生了什么变化。一次结果还可能同时受工具、时间、环境、目标与偶然因素影响，因此因果结论应对应到已经排除或记录的条件。

## 2. 判读证据强度

证据强度由表现内容与形成条件决定，而不是文件的创建工具、目录名或格式。计划、任务清单、课程和学习模型主要提供目标与假设；学习者实际完成的作品、判断过程、迁移表现和外部反馈直接支持能力结论。

用四个维度判读每个证据项目：

- **真实性**：表现来自真实任务、近真实任务还是只复述定义；
- **迁移度**：情境与已学例子相同、相近还是陌生；
- **独立性**：独立完成、追问后澄清、提示后修正还是教学后完成；
- **稳定性**：一次表现、重复表现还是跨情境表现。

| 展示 | 可以支持 | 结论边界 |
| --- | --- | --- |
| 脱稿解释定义、边界与关系 | 当前理解结构与知识阻塞 | 真实约束下的行动能力 |
| 对新输入作出判断并说明理由 | 条件识别与相近迁移 | 完整真实任务中的稳定表现 |
| 独立完成真实任务并得到反馈 | 知识参与了实际判断或行动 | 所有情境中的稳定掌握 |
| 提示或教学后完成 | 学习者能否借助支架继续 | 介入前已经具备该能力 |

一项表现可以支持多个主张，但每个主张分别记录它覆盖的部分。跨情境的独立表现逐步增强稳定性结论；空缺保持为“待验证”。

## 3. 定位最小阻塞

表现未达到预期时，先定位决定判断或行动的最小阻塞点：

| 观察到的差距 | 优先核查 |
| --- | --- |
| 能背术语，换一种说法就答错 | 定义或关键字义 |
| 知道单个概念，无法说明为什么这样选 | 概念之间的因果、前提或对比关系 |
| 熟悉例题，条件变化后误用 | 适用条件、边界或反例 |
| 解释成立，真实行动仍推进不了 | 前置技能、工具约束、环境条件或任务设计 |

概念相关证据继续区分四类内容：来源事实、教学解释、学习者工作定义与未知。来源不足时补可靠资料；通用定义成立但当前应用失败时，校正应用假设；真实行动受阻时，优先核查行动条件。

诊断采用“表现事实 → 原假设 → 具体差距 → 修正假设 → 下一项检验”。修正假设保持为当前证据能够支持的最小解释；多个解释仍成立时并列保留，并用下一项检验区分。

## 4. 将证据送回正确位置

| 已定位的问题 | 应校正的位置 | 下一步的最小检验 |
| --- | --- | --- |
| 来源不足、定义/边界/关系有误，或最小必要知识选错 | `learning-models/`、课程或参考资料 | 用修正后的概念解释旧案例，再完成一个新判断 |
| 输入、练习、反馈、资源或节奏不适合当前学习者 | `LEARNING-SOP.md` | 保持目标能力不变，只改变一个方法变量后比较表现 |
| 任务难度、顺序、场景或反馈来源无法暴露差距 | `TASKS.md` | 安排一项能暴露该差距的讲回、判断或真实任务 |
| 缺少独立表现、外部反馈或可观察结果 | 证据链 | 明确下一项展示及其完成条件 |
| 工具、时间或环境改变了结果 | 任务约束或执行条件 | 记录约束后完成一次可比尝试 |
| 证据反复挑战阶段方向或长期取舍 | 使命或战略决策 | 汇总跨检查点信号并重新审视对应决定 |

每项校正都是下一轮待检验的设计假设。复盘记录它由哪些事实触发、修改了哪个变量，以及下次用什么表现判断它是否成立。
