# 学习

学习流程中的 skill：

- [strategyfinder](strategyfinder/SKILL.md)：维护学习者唯一的长期战略地图，并逐张推进影响精力配置的战略决策。
- [grill-with-learn](grill-with-learn/SKILL.md)：通过上游 `grilling` 澄清学习使命或当前决策。
- [learn-modeling](learn-modeling/SKILL.md)：把指定材料按章节建成学习者能读懂的学习模型，供独立阅读或 `teach` 使用。
- [带我学](teach-me/SKILL.md)：以成甲的“问题—概念—行动—反思”闭环调用上游 `teach`，开展一轮对话优先的带学。
- [to-sop](to-sop/SKILL.md)：将已澄清的学习讨论整理为可持续执行的学习 SOP。
- [to-task](to-task/SKILL.md)：根据学习 SOP 规划下一批适应性学习任务。
- [study-review](study-review/SKILL.md)：在复盘检查点评估已展示的能力，并确定下一条路径。

`learn-modeling` 不做带学、练习或掌握评估；这些由 `teach` 和 `study-review` 完成。它也不记录学习过程或学习者证据。

创建或更新流程共享文件时，阅读 [ARTIFACTS.md](ARTIFACTS.md)。
