# 学习

学习流程中的 skill：

- [strategyfinder](strategyfinder/SKILL.md)：维护学习者唯一的长期战略地图，并逐张推进影响精力配置的战略决策。
- [grill-with-learn](grill-with-learn/SKILL.md)：通过上游 `grilling` 澄清学习使命或当前决策。
- [learn-modeling](learn-modeling/SKILL.md)：把指定材料按章节建成学习者能读懂的学习模型，供独立阅读或 `teach` 使用。
- [learn-one-concept](learn-one-concept/SKILL.md)：以轻量互动带用户学懂一个概念，通过讲回、判断或微行动形成证据；用户选择保存时再交给 `concept-card` 落盘。
- [concept-card](concept-card/SKILL.md)：将笔记中指定的一个概念做成可回溯、可判断和可行动的 Markdown 概念卡。
- [teach-me](teach-me/SKILL.md)：以“问题—概念—行动—反思”闭环调用上游 `teach`，开展有状态、跨会话的课程教学并沉淀课程工件。
- [to-sop](to-sop/SKILL.md)：将已澄清的学习讨论整理为可持续执行的学习 SOP。
- [to-task](to-task/SKILL.md)：根据学习 SOP 规划下一批适应性学习任务。
- [study-review](study-review/SKILL.md)：审查学习内容是否已改变真实判断或行动，并据此校正学习模型/课程、SOP 与任务。

`learn-modeling` 负责一份材料的章节模型；`learn-one-concept` 负责一次轻量、互动的单概念学习；`concept-card` 只在用户选择保存时成为本次学习的笔记工件。材料建模和概念卡都不替代持续教学或掌握评估；复杂教学交给 `teach`，阶段性能力判断交给 `study-review`。

各 skill 自带其创建文件所需的格式说明；[ARTIFACTS.md](ARTIFACTS.md) 只说明这套学习流程共享哪些工件及其边界。
