# 概念卡质量检查

交付前逐项检查。任一核心项缺失时，优先标出缺口或向用户只问一个必要问题，而不是填充流畅但无依据的文字。

| 检查项 | 合格标准 | 常见失败 |
| --- | --- | --- |
| 单一范围 | 卡片只有一个可命名的概念，且来源范围可回溯 | 把一节材料、一个主题或多个并列概念塞进一张卡 |
| 问题牵引 | 写明该概念解释的现象或支持的判断 | 只有百科定义，没有“为什么现在需要它” |
| 一字一义 | 定义、当前含义、机制与边界互不混淆 | 用同义词替代定义；把比喻当成定义 |
| 最小概念束 | 只保留 2–4 条关系，并标明关系类型 | 罗列相关名词，或画一张无法使用的知识网 |
| 区分力 | 正例与易混淆反例揭示关键条件 | 只给一个成功故事；反例与概念毫不相干 |
| 行动检验 | 给出 `输入 → 判断 → 行动`，或诚实标记场景待补 | 虚构学习者经历；把阅读或记忆当作行动 |
| 知识诚实 | 来源事实、教学解释、假设与未知分别可见 | 把笔记作者的推断说成事实；把 AI 推导伪装为原话 |
| 来源导航 | 每项来源事实能回到笔记片段或明确资料 | 只写书名、网页名或“根据笔记” |
| 掌握边界 | 不因产出卡片而声称理解或掌握 | 用“已掌握”“已经内化”替代真实表现证据 |

## 快速裁决

- **可交付：** 所有核心项都有可靠内容，或缺口已明确标注。
- **需要缩小：** 选区包含多个概念，先让用户选一个。
- **需要补来源：** 当前片段不足以支持定义、边界或例子，说明哪一项缺少证据。
- **需要进入教学：** 卡片已经足够，但用户想练习解释、判断或迁移时，交给 `teach-me`。
