# 成甲学习效果审查依据

本文件将《好好学习：个人知识管理精进指南（升级版）》与《好好思考（全新升级版）》中直接影响学习复盘的判断，压缩为 `study-review` 的执行依据。它不替代原书，也不把课程完成、记录数量或流畅表达误当成学习效果。

## 原书依据

- 《好好学习》第 2 章“学习的本质是什么”：学习是让原有假设更接近事实，从而改进判断与决策；知识积累本身不会自动带来深度思考。
- 《好好学习》第 2 章“反思：提升知识掌握的层次”：反思不是评价结果好坏，而是按“观察结果 → 研究原先假设 → 校正假设”追溯结果的原因。书中还指出反思可发现误区、从已有知识产生新知识，并检查新知识是否已用起来。
- 《好好学习》第 2 章“以教为学、刻意练习、记录与定期回顾”：解释、练习、记录和回顾的价值在于暴露理解差距、形成反馈并改进行动，而不是累积完成数量。
- 《好好思考》第 2、3、4 章：“不读书法”要求暂停输入，把观点接到真实问题和下一步行动；“对知识的诚实”要求承认不知道与概念边界；最小必要知识只服务具体问题，必须在实践中检验。

## 审查对象

一次复盘要审查的不是“有没有完成计划”，而是一条可被检验的学习效果主张：

```text
真实问题
  → 本轮最小必要知识（概念、关系或方法）
  → 原本预期改变的判断 / 行动
  → 实际表现与真实结果
  → 对内容、方法与任务假设的校正
```

课程、学习模型、SOP 和任务都只是为这条变化服务的设计；它们可以被证据支持、削弱或推翻。

## 证据强度

优先观察学习者能否独立完成真实任务、在不看材料时重建关键概念与关系，或将其迁移到相近陌生情境。完成课程、阅读时长、笔记数量、自述熟悉和只会复述术语只提供背景，不能直接证明效果。

讲回是有价值的中间证据：它能暴露概念是否说清、边界是否混淆、关系是否断裂；但如果目标是现实行动，还需要行动结果或迁移检验。

## 反思与校正

严格区分：

- **结果/事实**：学习者实际做了什么、说了什么、得到什么反馈；
- **原假设**：为什么当初认为这份内容、学习方法或练习会有效；
- **差距**：实际效果与预期变化在哪里不同；
- **修正假设**：哪一项内容、方法、任务或条件更可能解释结果；
- **下一步**：用一个更小、可观察的行动继续验证。

不要因为一次失败就断定学习者不行，也不要因为一次流畅讲回就宣布掌握。证据不足时承认不知道，并先设计最能区分原因的下一次练习。

## 校正去向

| 证据显示的问题 | 应校正的位置 |
| --- | --- |
| 最小必要知识选错、前置概念缺失、概念边界或关系未讲清、材料无法服务真实问题 | `learning-models/` 与课程/参考资料 |
| 输入、练习、反馈、资源、节奏或检查点不适合当前学习者 | `LEARNING-SOP.md` |
| 任务难度、顺序、情境、反馈来源或完成条件不能暴露/改进差距 | `TASKS.md` |
| 没有公平、独立的表现证据 | 设计下一项真实任务、讲回或迁移检验 |

内容、SOP 或任务的更新都是新的可证伪假设，不可反过来充当已经产生学习效果的证明。
