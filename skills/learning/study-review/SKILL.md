# 学习效果审查

审查的中心是**学习效果**：本轮学习的最小必要知识，是否让学习者在真实问题中形成了更好的解释、判断或行动。课程完成数、投入时长、笔记数量、任务勾选与熟悉感都不是效果本身。

`LEARNING-SOP.md` 与 `TASKS.md` 是有待检验的学习假设，不是复盘的评分标准。复盘先看学习内容是否产生效果，再依据差距判断该修正学习模型或课程、SOP、任务，还是补收证据。

开始前阅读 [成甲的学习效果审查依据](references/chengjia-learning-effect-review.md)。

## 锁定本次要审查的学习内容

阅读 `MISSION.md`、`LEARNING-SOP.md`、`TASKS.md`、相关 `learning-models/`、课程与参考资料、`learning-records/`、真实练习产物和既往复盘。先从本次实际学习的内容中选出一个或少数几个可审查单元；不要只拿流程文件做检查。

对每个单元，写清：

1. **真实问题与最小必要知识**：它原本要帮助学习者解决什么问题，关键概念、关系或方法是什么。
2. **预期效果**：若真的学会，学习者应在什么情境做出什么不同的解释、判断或行动。
3. **待检验的设计假设**：原先是否假定这份学习模型/课程内容足够、SOP 的方法适合、TASKS 的练习与反馈能产生该效果；缺失时标为“未记录”。

学习者口述“我懂了”只能作为待检验假设，不能替代上述预期效果。

## 收集学习效果证据

从结果和实际表现开始，而非从课程进度开始。每项缺少强证据的学习内容，只要求一个最小但足够令人信服的展示，优先顺序是：

1. 独立完成的领域真实任务；
2. 在不打开材料时，解释关键概念的边界和关系，并用它重构一个案例；
3. 在相近但陌生情境中作出判断、说明理由或采取行动。

一项展示可以支持多个学习单元时可以合并，但必须分别说明各自的证据。每次回答后只追问获得结论所需的下一项证据。当前无法公平评估时标为“待验证”，不要把空白补成失败或掌握。

把**表现事实**、**对事实的解释**与**修正后的假设**分开。讲回可以证明部分理解，但不能自动证明真实迁移；一次偶然成功也不能自动证明稳定能力。

## 用效果诊断学习设计

先判断学习内容的效果，而不是先决定要不要推进：

- **有效**：学习者能用本轮关键知识解释、判断或行动，且表现符合预期效果。
- **部分有效**：能复述或在熟悉情境使用，但在关键边界、关系或迁移上仍有具体缺口。
- **未产生预期效果**：有足够证据表明当前学习内容尚未带来预期判断或行动改变。
- **待验证**：没有公平、独立的效果证据。

对“部分有效”或“未产生预期效果”，按“结果 → 原假设 → 差距 → 修正假设 → 下一步”定位原因。至少区分以下可能性，不能把所有问题一律归因于学习者练得不够：

1. **学习内容或材料模型**：最小必要知识选错、缺少前置概念、概念边界/关系未讲清，或课程与真实问题脱节；
2. **学习方法（SOP）**：输入、练习、反馈、节奏或资源策略不适合学习者与目标；
3. **任务设计（TASKS）**：任务难度、顺序、情境、完成条件或反馈来源不足以制造有效练习；
4. **执行条件**：时间、工具、环境或其他已记录约束改变了结果；
5. **证据不足**：目前不能在上述因素间作出诚实判断。

诊断是修正下一轮假设的依据，不能替代效果证据，也不能把学习者自责或流畅表述伪装成原因。

## 写入复盘并校正下一轮

按 [`../ARTIFACTS.md`](../ARTIFACTS.md) 的格式写入 `reviews/<date>-<checkpoint>.md`。报告以每项学习内容的预期效果、事实证据、效果状态和诊断为主；再列出哪一项设计假设被支持、削弱或仍未知。

根据诊断选择可组合的校正动作：

- **内容问题**：交给 `learn-modeling` 更新材料模型、前置知识桥或来源；交给 `teach-me` 更新课程、参考资料或练习。内容修正本身是新的假设，不能倒过来证明原来已学会。
- **SOP 问题**：在学习者确认后交给 `to-sop` 修订目标能力、学习方法、资源策略或检查点。
- **TASKS 问题或证据不足**：交给 `to-task` 重排当前任务，设计能暴露差距的真实任务、讲回或迁移；根据已收集的事实更新已有任务状态。
- **效果有效**：保留已证明的能力证据，并让 `to-task` 推进下一个仍服务于学习使命的学习块。

只有确认了持久理解、纠正了误解，或发生会改变后续教学的变化时，才新增 `learning-records/`。不得静默改写学习使命、SOP 的实质约束或学习模型的来源结论。

## 交接

清楚说明：审查了什么学习内容、预期与实际效果、支持该判断的证据、已被校正的假设，以及内容/SOP/TASKS 中各自的下一步。不要只输出“继续”或“补强”。

完成条件：每个选定学习单元都有诚实的效果状态；至少一项独立或真实证据支撑每个非“待验证”结论；学习者知道下一步应校正内容、SOP、TASKS，还是补收哪一项证据。
