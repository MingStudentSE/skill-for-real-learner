# 生成学习任务

将当前学习 SOP 转化为一小批可执行的学习任务。任务是能产生练习或学习证据的行动。

## 读取规划上下文

阅读 `MISSION.md`、`LEARNING-SOP.md`、当前的 `TASKS.md`、相关 `learning-records/`，以及最新复盘报告（如果存在）。以学习者已展示的起点和 SOP 中的目标能力为准，不安排已经证明掌握的内容。

如果工作区没有当前学习 SOP，说明缺少生成任务所需的规划依据。如果请求的时间范围不清楚，只问一个简短问题；否则从请求中推断最小且有用的范围。

## 适应性规划

先阅读 [`TASKS.md` 格式](references/task-format.md)，再创建或修订 `TASKS.md`，只规划当前批次：

- **月计划**设定少量能力里程碑和重要检查点。
- **周计划**选择确实能推进这些里程碑的工作。
- **日计划**结合学习者的时间与精力选择下一步练习。
- **单次学习**给出一项可立即开始的行动。

更细的计划继承较粗计划，但可随新证据调整。远期内容只保留为里程碑，不假装能提前知道精确的课程顺序。

每项任务都要有目标能力、行动、可见的完成条件、证据、练习与反馈、现实的投入与节奏、依赖关系和状态。优先设计短闭环：在具体情境中尝试，用来自他人、工具、标准或环境的反馈对照，再据此调整下一次行动。关键输入只有转化为关联、问题或一次可检验的尝试，才成为任务的一部分。

- 独立完成的小任务；
- 不打开课程材料的复述；
- 在相近但陌生情境中的应用；
- 来自他人、工具或环境的领域反馈。

不要将课程完成数或阅读时长当作能力证据。`teach` 可以为一项任务创建多节课与多次练习；同一学习领域的课程会在工作区中持续累积。

## 确认任务批次

用紧凑列表展示任务标题、证据、练习与反馈、投入和依赖关系，询问任务量、时间和顺序是否符合学习者的现实。采纳修正后再写入当前计划。

## 输出

交付或更新 `TASKS.md`，指出当前无依赖、可立即开始的任务，以及它们的证据、练习与反馈、投入、依赖和计划复盘检查点。后续流程可以读取这一工件；本 skill 不在此处启动教学或复盘。

完成条件：`TASKS.md` 包含现实可行的当前任务批次，第一项无依赖任务可立即开始，且完成后会产生有价值的证据。
