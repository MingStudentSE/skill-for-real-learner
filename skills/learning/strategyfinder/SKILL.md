# 学习战略寻路

把长期战略视为学习者所有学习、项目、任务与取舍共同服务的唯一方向。维护一张长期存在的 `STRATEGY-MAP.md` 和其决策卡；不要因进入新阶段另建一张战略地图。

战略图负责找到和维护路线，不替代路线上的执行。清晰的下一步交给 `to-sop`、`to-task`、`teach` 等现有 skill；执行产生的新证据只在学习者下次主动调用时回到地图。

读取 [`references/map-format.md`](references/map-format.md) 创建或更新战略地图与决策卡。需要判断战略质量或选择首批决策时，读取 [`references/strategic-lenses.md`](references/strategic-lenses.md)。

## 长期复利的使用边界

长期战略不等于把所有学习都放大，也不等于预测某个方向必然成功。对会改变长期方向、占用显著精力，或一旦投入就很难撤回的选择，使用 `strategic-lenses.md` 中的“长期复利与不失败”镜头；普通课程、短期任务和低成本尝试不要强行套用。

先确认学习战略可持续的底座：哪些约束、承诺或资源一旦被持续侵蚀，会使这条路线失效。只记录与战略相关的护栏、预警信号和可逆性，不把战略地图扩展成健康、财务或家庭管理计划，也不要要求学习者提供不必要的私密信息。

对适用的选择，明确一条可被证伪的复利假设：当前的重复投入将沉淀什么能力、资产、关系或选择权；它怎样降低未来成本、提高未来质量或扩大上行。将支持证据、未知条件和反证信号分开记录。不要用五项原则打分，也不要把“可能有复利”写成事实或关闭依据。

## 适用边界

当学习者主动要求审视长期学习方向、重新配置有限精力、在多个长期机会间取舍，或继续推进已有战略地图时运行本 skill。

普通课程讲解、单次作业、日计划、已经明确的学习任务与泛泛的职业焦虑不进入本 skill；分别交给 `teach`、`to-task` 或当前对话处理。不要把短期执行波动误写成战略改变。

## 先读取证据

仅在学习者主动调用后行动。先扫描当前学习工作区的笔记、日记、学习记录、任务、产出与既有战略工件；额外笔记库或文档只在学习者明确提供位置或授权后读取。

从材料中分别记录：

- 已观察到的事实与已完成的产出；
- 学习者当前自述的目标、偏好和约束；
- 由多条材料得出的推断；
- 缺少证据的未知项与相互冲突的说法。

笔记不会自动压过学习者当下的陈述。当二者冲突时，建立一张 `grilling` 决策卡，由学习者沟通后再作判断。

## 模式一：绘制战略地图

当不存在 `STRATEGY-MAP.md`，或学习者要求重新看清长期方向时：

1. 运行 `/grilling`，以设计树澄清总体战略、当前阶段、精力配置原则、主要约束与当前无法决定的事项。不要另造固定问卷或限制问题数量。
2. 形成能量与可迁移优势审计：从真实记录和经历中找出持续充能/消耗、已有能力、可迁移能力与仍需验证的假设。四维评分、心流、天赋、嫉妒、锚问题和奥德赛计划仅在它们能推进当前决策时使用。
3. 对已出现的长期下注，先记录不失败底座，再按复利镜头找出最少的关键未知项。只选择足以改变取舍的一到两个条件建立验证，不建立完整模型清单或形式化评分表。
4. 创建或更新总图，写入已能共同确认的内容；把仍不够精确的事项留在“尚未明确”。
5. 为已可表述的问题创建首批决策卡；先创建卡，再写入依赖关系。对长期方向或重大资源配置卡，写入护栏、复利假设与反证信号。不要在建图会话中关闭任何决策卡。
6. 停止。说明当前前沿、尚未明确的迷雾与下一次可主动推进的卡。

总体战略不是阶段愿望或任务集合。只有当学习者主动沟通，且双方确认新的长期目标、现实约束或关键证据已经推翻原战略时，才允许修改它；在修订记录中保留旧战略、新战略、原因与证据。

## 模式二：推进一张战略决策卡

当学习者提供地图或要求继续时：

1. 加载总图的低分辨率内容；只在需要时读取相关已关闭卡。通过决策卡的状态与依赖找到当前前沿。
2. 优先使用学习者点名的卡；否则选择第一张未关闭、无未解决依赖的卡。一次调用只推进这一张卡，`research` 卡可并行。
3. 按卡类型行动：
   - `research`：调用 `/research` 补足外部事实、一手资料或可验证数据；不要让学习者替 agent 查本可查的事实。
   - `grilling`：调用 `/grilling`，让学习者做价值、取舍、承诺或战略修改判断。
   - `prototype`：定义最低成本的学习或真实场景实验、观察信号和停止条件；交给执行 skill，不在本 skill 中执行实验。
   - `task`：明确必须完成的前置行动及完成证明；交给执行 skill，不把它伪装成战略决策。
4. 只在卡拥有对应关闭证据后，写入结论并关闭它：研究有可引用事实，沟通有学习者明确取舍，原型有真实实验结果，任务有前置行动完成证明。对长期方向或重大资源配置卡，结论还要说明不失败护栏是否仍成立，以及哪些复利假设已获支持、仍待验证或已被反证；不得把未验证的上行当作既定战略。
5. 在总图“已定战略”中追加指向已关闭卡的一行摘要。把新出现且足够明确的问题建成新卡；仍模糊的内容留在“尚未明确”；确认不服务总体战略的事项移入“明确不做”。

战略取舍始终以决策卡为权威来源，不要用 `learn-modeling` 记录战略结论。当前阶段进入特定材料学习时，`teach` 可以调用 `learn-modeling` 建立材料模型；模型本身不改变战略结论。

## 完成与交接

当当前阶段不存在可推进的前沿卡，且没有可具体化的迷雾时，只宣布“当前阶段路线清晰”。不要宣布长期战略或人生已经完成。

路线清晰后，将已确认的当前阶段和能力方向交给 `to-sop`；将已确定的实验或前置行动交给 `to-task`。在交接中指出战略地图、相关已关闭决策卡和仍需回到地图验证的假设。

`to-sop` 和 `study-review` 继续负责阶段方法、能力证据与局部假设校正，不自动修改战略地图。仅当复盘反复显示行动成本不可持续、底座护栏被触发、资产没有形成、关键假设被反证，或出现会改变总体取舍的新事实时，才在学习者下一次主动调用本 skill 时新建或重开战略决策卡。
