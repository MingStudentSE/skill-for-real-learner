# 战略地图与决策卡格式

`STRATEGY-MAP.md` 是唯一长期战略的低分辨率索引。它不重复决策卡的细节；未关闭的卡通过 `strategy-decisions/` 中的状态与依赖发现。

```md
# 战略地图：<战略名称>

## 总体战略

<学习者所有学习、项目与取舍共同服务的长期方向。不是待办清单，也不是阶段愿望。>

## 当前阶段

<当前阶段的目的、约束、正在验证的核心假设。>

## 战略原则

- <有限精力如何配置的稳定原则>

## 不失败底座

- <必须守住的战略相关条件>：<护栏、预警信号或可逆性要求>

## 复利假设

- <当前长期投入会如何沉淀能力、资产、关系或选择权，并降低未来成本或扩大上行；未验证时明确标注为假设>

## 已定战略

- [<已关闭决策卡标题>](strategy-decisions/<file>.md) — <一行结论>

## 尚未明确

- <仍在战略范围内、但尚不能精确写成决策卡的迷雾>

## 明确不做

- <不服务总体战略的方向或机会，以及原因>

## 战略修订记录

- <日期>：<仅在确认原战略被推翻时，记录旧战略、新战略、原因与证据>
```

## 决策卡

每张卡只解决一个战略问题，保存在 `strategy-decisions/`。使用状态与依赖表达当前前沿；不要在总图复制未关闭卡的细节。

```md
---
type: research | grilling | prototype | task
status: open | claimed | closed | out_of_scope
depends_on: []
---

# <决策卡标题>

## 问题

<这张卡需要作出的单一战略判断或完成的前置事项。>

## 证据与假设

- **事实：** <已观察、可复查的材料或产出>
- **自述：** <学习者当前的目标、偏好或约束>
- **推断：** <由多条材料形成、仍需验证的判断>
- **未知：** <仍缺少什么>

## 长期复利判断

仅在这张卡决定长期方向、重大精力配置或高不可逆选择时填写；其他卡写“未适用”，不要制造形式负担。

- **不失败底座：** <需要保护什么；当前护栏、预警信号和可逆性>
- **复利假设：** <重复投入将沉淀什么，以及如何降低未来成本、提高质量或扩大上行>
- **关键条件：** <当前支持证据与尚未验证的条件；不要把假设写成事实>
- **反证或暂停信号：** <什么结果会要求暂停、缩小投入或重开战略判断>

## 关闭条件

<research / grilling / prototype / task 对应的必要证据>

## 结论

<仅在关闭时填写；链接证据与下一步。>
```

## 状态规则

- `open`：已精确表述，但尚未被领取。
- `claimed`：本次调用正在推进；不要让并发会话重复处理。
- `closed`：满足关闭条件，结论已链接回总图。
- `out_of_scope`：确认不服务总体战略；保留原因，不计入已定战略。

卡的依赖未全部 `closed` 前，不是当前前沿。`research` 卡可以并行；其他卡在一次调用中只推进一张。
