# 学习者战略判断镜头

这些镜头用于提出和检验战略假设，不用于给学习者贴人格标签、预测未来或保证收益。

## 能量与能力

长期下注必须同时看三个信号：

1. **能量**：活动结束后是长期充能还是持续耗竭；
2. **能力**：已展示的能力与可迁移的工作方式，而不只是自我感觉擅长；
3. **现实问题**：这条能力是否服务一个具体、重要、可接触的问题。

三者任一缺失，都把方向写成假设并建立验证卡。天赋、心流、嫉妒、童年偏好、工作观与人生观都是可用证据，不是自动结论。

## 精力配置

先问有限精力放在哪里最能推进总体战略，而不是什么方向听起来更大、更热门或更体面。每个候选学习方向至少回答：

- 它服务总体战略的哪一部分？
- 它会积累还是分散现有的可迁移能力？
- 放弃它的机会成本是什么？
- 有什么更小、更可赢的场景可以先验证？

## 长期复利与不失败

只在比较长期方向、重大精力配置或高不可逆选择时使用本节。它不是收益预测器，也不要求把每项活动做成五维评分表。

先确认**不失败底座**：这项选择长期推进时，什么会被持续侵蚀，以至于学习者无法继续走这条路线？只记录和战略有关的约束、承诺、资源边界、可逆性与早期预警信号。不要将这一检查延伸为未经请求的健康、财务或家庭建议。

在底座可守住的前提下，为候选方向形成一条**复利假设**：重复投入会沉淀什么可迁移能力、作品、流程、信任、数据或选择权；这些沉淀如何让下一次投入成本更低、质量更高或上行更大。假设必须能被后续事实支持或推翻。

按当前问题选用下列镜头；通常一到两个最关键的未知项就足够：

1. **内驱力**：真实记录是否显示这件事能持续供能，而不只是新鲜感或外部期待？与“能量与能力”镜头交叉核对。
2. **趋势与真实需求**：更长时间尺度下，外部环境或真实问题是否支持这项投入？需要外部事实时建 `research` 卡，不凭印象预测趋势。
3. **关键解与认知增益**：它是否让学习者更理解一个会反复出现的关键问题，或显著增强可迁移能力？避免把“新知识更多”误当成认知增益。
4. **边际成本与资产沉淀**：重复后哪一部分会变得更容易、更可靠或更可复用？若不能说明沉淀物，只能称为一次性收益。
5. **不对称上行与可承受下行**：失败时损失是否可控、可逆，成功时是否有合理但尚未保证的额外上行？将上行记为假设，先保护底座再设计小实验。

对需要进一步推进的镜头，决策卡至少留下四件事：当前支持证据、尚未验证的条件、最小验证动作，以及反证或暂停信号。不要因为某个镜头表现良好就忽略其他已知风险。

## 适用条件与回流

- 普通课程、确定的任务和低成本尝试继续使用原有的精力配置与验证优先镜头；不要把它们升级成长期复利判断。
- 学习 SOP 的最小必要知识、节奏和反馈循环由 `to-sop` 维护；本文件只判断值不值得长期投入。
- `study-review` 中的一次表现波动不足以修改战略。只有反复的成本、能量、护栏、资产或关键假设信号，才在学习者下次主动进入 `strategyfinder` 时升级为决策卡。

## 验证优先

将大而模糊的愿望拆成低成本原型：一次真实任务、小范围服务、作品、访谈、试讲、代码修改或带反馈的练习。原型只为消除一个关键不确定性；先定义观察信号和停止条件，再投入更多精力。

## 证据语言

- **事实**：已有记录、可复查产出、外部一手信息或完成的实验；
- **自述**：学习者的体验、偏好、目标和约束；
- **推断**：从若干材料综合出的判断；
- **未知**：尚不能判断的事项。

冲突不靠 agent 静默裁决。把冲突转成 `grilling` 卡，与学习者确认后再更新战略地图。
