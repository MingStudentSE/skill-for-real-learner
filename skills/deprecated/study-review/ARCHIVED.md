# 学习效果审查

建立一条可检查的**证据链**：要证明的能力 → 独立表现 → 结论 → 学习设计校正。课程完成数、投入时长、笔记数量与文件来源只提供语境；结论由表现支持。已有文件与现场展示都作为证据项目进入同一条证据链。

在判读证据强度、限定因果结论或定位学习设计问题时，查阅[学习效果审查依据](references/learning-effect-review.md)。

## 1. 确定证明目标

把“我学会了吗”改写为一个或少数几个可观察主张：学习者应在什么情境下，使用哪些关键知识，作出什么解释、判断或行动。

1. 以用户点名的概念、能力或材料为范围；范围过大时，选择本轮能够公平检验的单元。
2. 用户提供参考材料时，从材料实际覆盖的定义、边界和关系建立判断标准并保留来源定位。没有材料时，从可靠来源建立最小标准；定义易变、领域陌生或风险较高时先查证。
3. 工作区存在相关工件时，读取 `STRATEGY-MAP.md`、`MISSION.md`、`LEARNING-SOP.md`、`TASKS.md`、学习模型、课程、学习记录与既往复盘中和本次主张直接相关的部分，用它们恢复真实问题、预期效果和原设计假设。
4. 用学习前状态与后续表现检验“发生了变化”；只有当前表现时，检验“目前达到目标”。

本步完成条件：每个主张都写清情境、预期表现、关键知识、判断依据和允许作出的因果范围。

## 2. 收集独立表现

先盘点当前对话、用户指定文件和工作区材料。把每项相关材料记录为一个**证据项目**：来源、独立性、实际表现、能够支持的主张、证据边界和介入程度。

- 计划、课程、学习模型与摘要用于恢复目标或假设；其中只有学习者的原始回答、判断过程或真实表现进入能力证据。
- 真实任务、作品、代码、解题过程、判断记录及外部反馈优先支持行动表现。
- 脱稿解释、边界辨析和陌生情境判断支持当前理解与迁移。
- 转述、提示后修正与教学后完成按实际介入程度记录。

现有证据足够区分结论状态时，直接进入下一步。证据出现缺口时，设计一个最小展示，依次优先选择真实或近真实任务、陌生情境判断、脱稿解释。

现场展示先记录一次**无提示基线**：首题只呈现情境与必要约束。随后根据回答逐次追问依据、适用条件、边界、反例或条件变化；每次只收集当前结论缺少的一项证据。介入发生后，分别记录追问后澄清、提示后修正和教学后完成，并用相近但不同的情境重新检验。

本步完成条件：每个主张都有足以判断状态的证据，或已明确唯一缺少的证据；每次提示与教学都能定位到介入前后的表现。

## 3. 给出证据化结论

对每个主张分别给出状态：

- **达到预期**：独立表现覆盖关键知识与预期情境；
- **部分达到**：熟悉情境中的解释或判断成立，具体边界、关系或迁移仍有缺口；
- **未达到预期**：充分且公平的表现显示关键解释、判断或行动尚未出现；
- **待验证**：现有独立表现不足以作出公平判断。

结论分开呈现表现事实、事实支持的解释、仍待验证的假设与证据边界。一次表现只支持它实际覆盖的情境和稳定程度。

本步完成条件：每个非“待验证”状态都能指向至少一项独立表现；每个状态都说明已经证明与尚未证明的范围。

## 4. 校正学习设计

存在既有学习设计时，按“结果 → 原假设 → 差距 → 修正假设 → 下一步”定位证据应送回的位置，并使用审查依据中的诊断矩阵：

- **学习模型/课程**：形成带来源与边界的具体修正；学习者确认后更新内容、前置知识桥、课程或参考资料。
- **`LEARNING-SOP.md`**：形成只改变必要方法变量的修订建议；学习者确认后更新目标能力、练习、反馈、资源、节奏或检查点。
- **`TASKS.md`**：依据事实更新任务状态与证据链接；新增、停止或重排任务前先确认新的任务假设。
- **使命或战略**：只在本次复盘记录足以影响阶段方向或长期取舍的信号，并明确下一次需重新审视的决定；`MISSION.md` 与 `STRATEGY-MAP.md` 标记为“保留”，直到学习者在对应决策中确认改变。
- **执行条件或证据不足**：记录约束或下一项展示，让下一轮只改变一个可比较变量。

内容、SOP 与任务的修改都是下一轮要检验的新假设；修改记录不参与证明本轮已经掌握。

本步完成条件：每个相关工件都被标记为“保留并说明理由”“已确认并更新”或“交给后续决策”；所有实际修改都能回到本轮证据。

## 5. 写入复盘

按[学习复盘格式](references/review-format.md)写入 `reviews/<date>-<checkpoint>.md`。用户选择只在对话中接收结论或当前环境不支持写入时，使用同一结构交付。

只有确认了持久理解、纠正了误解，或出现会改变后续教学的变化时，才新增 `learning-records/`。

最终完成条件：整条证据链可追溯；每个主张有诚实状态；介入程度清楚；每个既有学习工件都有处理决定；学习者知道唯一下一步。
