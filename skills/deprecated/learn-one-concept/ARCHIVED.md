# 学一个概念

带学习者完成一个小而完整的概念学习回合。目标不是给出漂亮定义或完成一份笔记，而是让学习者能脱稿说明概念、区分它的边界，并在一个情境中完成 `输入 → 判断 → 行动`。全程一次只问一个问题，保持轻量；通常在约 30 分钟内收束。

开始前阅读[单概念学习的分支判断](references/learning-loop.md)。

本 skill 只推进一个可命名的概念。不要将一个主题、一套方法论或多个并列概念伪装成“一个概念”。

## 选择概念与来源

1. 确认用户已经点名一个概念。若材料中有多个候选概念但用户没有选择，给出不超过 3 个候选项、各自解决的问题和来源位置；等待用户选定一个再继续。
2. 确认来源。用户给出材料时，先读足以支持定义、边界、机制和例子的最小范围，保留页码、章节或锚点。用户没有材料时，先检索可靠来源；技术、医学、法律、财务等高风险话题优先一手资料或权威规范。
3. 区分四类内容：**来源事实**、**教学解释**、**学习者假设**、**未知**。不能把搜索摘要、类比或自己的推导说成来源事实。

## 运行轻量学习回合

1. **了解起点。** 只问一个起点问题。对问题型学习，问学习者想完成什么行动或目前卡在何处；对好奇型学习，问它为何吸引学习者、已经知道什么。没有回答时，按具备一般阅读能力的高中生起点讲解，并明确这只是暂定假设。
2. **确定本轮目标。** 将目标写成一次可观察的展示：学习者要能解释什么、区分什么，或用它做出什么判断。只补足当前展示所需的最小知识，不追求概念地图完整。
3. **小步建立概念。** 每次只引入一个必要点，按“人话含义 → 通用定义 → 它不是什么／何时不适用 → 最短机制或关系 → 当前情境有什么用”组织。讲解后暂停；不要连续灌输。
4. **将输入接到经验。** 遇到可能改变判断的观点，先让学习者回答一个问题：它解释了什么现象、连接了什么已有经验，或下次会让自己作出什么不同判断。未得到回答前，不继续扩展输入。
5. **要求学习者展示。** 按参考层的展示分支，选择最小且贴近当前证据缺口的一种展示。好奇型学习没有真实场景时，使用构造情境；保持它与学习者经历明确分开。
6. **按差距纠偏。** 按参考层的纠偏阶梯处理定义、边界、关系或适用条件的差距，直到新情境已经重新检验，或留下一个明确的证据缺口。学习者始终亲自完成判断。
7. **收束而不夸大。** 用一两句话说明已出现的证据、尚未验证的假设和唯一下一步。真实行动已经发生时，可按“结果 → 原假设 → 差距 → 修正 → 下一步”复盘；一次讲回、阅读或答对不等于掌握。

## 可选模型笔记

学习回合完成后，只问一次学习者是否要将这个概念保存为模型笔记。

- 学习者不保存：在对话中交付本轮结论，不创建文件。
- 学习者保存：将本轮已经核实的来源内容、来源定位、教学解释和明确标注的学习者假设组成一个简短、可追溯的输入，复用 `learn-modeling` 建立单概念学习模型。沿用其 `learning-models/<date>-<topic>.md` 布局；不得覆盖无关文件。

模型笔记只保存知识内容和应用假设。学习者的讲回表现、反馈和掌握判断留在本轮对话或学习记录中；没有可靠来源、边界或例子时，先补足或诚实标为待验证。

## 完成条件

结束时必须具备：一个已锁定概念、可靠来源或明确的证据缺口、学习者自己的解释或判断、一次针对差距的反馈，以及一个唯一下一步。缺少其中任何一项时，继续当前回合或清楚说明为何无法继续；不要用长总结掩盖缺口。
