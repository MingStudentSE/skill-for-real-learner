# AGENTS.md 生成规则

生成前按入口要求调用 `/writing-for-agents`；缺失时报告依赖缺口，不自行宣称已执行。

## 解析路径

读取现有入口及用户实际结构，逐个解析以下路径，转换为相对于目标 `AGENTS.md` 的 Markdown 链接。目录可以分别改名或调整层级。

| 模板参数 | 实际目标 |
| --- | --- |
| `{{user_path}}` | `USER.md` |
| `{{soul_path}}` | `SOUL.md` |
| `{{rules_index_path}}` | 规则目录的 `index.md` |
| `{{maintenance_rule_path}}` | 知识库维护规则笔记 |

根索引固定相对于库根。链接目标缺失时先由搭建流程处理；只设计模板的任务不创建实际知识库。

## 合并模板

使用 [精简模板](../assets/AGENTS.md.template)，替换实际路径；新入口不扩充正文，额外约定由用户后续添加。已有入口保留有效的用户指令和读取顺序，只合并必要指针。

字段细则与验收步骤留在规则笔记，完整 Spec 按相关章节查阅。入口只引用两份画像，不加入画像维护章节或特定 Skill 调用。

## 验证

检查占位符已替换、链接目标存在、规则读取条件明确；已有属性与用户约定未丢失。用户改名后更新指针，沿用新结构。
