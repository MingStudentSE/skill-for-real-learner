# 学习工件

本文件定义当前九个 skill 之间共享的状态边界。具体格式由各自 skill 携带，公共配置写在用户工作空间；使命、计划、任务与教学证据分别写入当前学习项目，沿用 setup 保存的实际路径。项目目录相对工作空间根，项目内状态路径相对项目根；以下是默认文件名。

## 环境配置

`setup-learn-skills` 保存 `docs/agents/learning.md`（或用户已有位置），并在根 Agent 指令中维护摘要与指针。一个根 `AGENTS.md`（或已有权威入口）承载公共指针，配置支持一个或多个项目文件夹，说明项目定位、状态路径、可用入口及读取规则，不预先生成项目、任务、计划、课程或学习画像。项目选择按明确指定、当前目录、对话已明确项目、唯一项目的顺序解析；无法确定时询问，不跨项目猜测。

## 战略地图与决策卡

`strategyfinder` 维护 `STRATEGY-MAP.md` 和 `strategy-decisions/`，保存长期方向、重大取舍、护栏、证据和未决假设。只有用户主动沟通并确认时才修改战略。计划、任务或教学中的变化不自动改写战略。

格式见 [战略地图](learn/strategyfinder/references/map-format.md)。以 `grilling` 为主干，从实践、时间/金钱/精力投入及反馈分析候选方向，决策卡保存关键假设、按需查证的外部事实与证据摘要，以及低成本真实测试的行动、观察信号和停止条件。复盘记录实际投入、反馈与假设变化，由用户决定加码、维持、缩小或暂停；不强制研究子代理、独立研究笔记或代码原型。

测试记录、反馈及按需产生的研究笔记或原型保存在用户工作区，路径由卡中的上下文指针记录。提交临时分支、修改真实实现和 issue 操作仅在用户明确授权后执行；未授权时本地保存并更新卡的上下文指针即可。

## 使命与学习计划

`to-plan` 与用户聊清楚学习目标和个人情况，共同讨论并调整具体方案，取得明确同意后才创建或更新 `LEARNING-PLAN.md`。战略、使命文件与前置质询均非必要条件，缺少时无需补建。计划自身写清学习原因、成功标准、约束、能力目标、起点、范围与深度、路线、资源、练习方法、现实节奏及检验点，并记录个人条件如何影响这些选择。已有 `MISSION.md` 或战略仅作相关参考，未经明确要求不改写。计划格式随 [to-plan](learn/to-plan/SKILL.md) 提供；教学所需使命由教学入口按需维护。

旧 `LEARNING-SOP.md` 可作为迁移输入，不能仅改标题冒充完整计划；先核对仍有效的内容与未知，保留原文件。目标与旧资料冲突且尚未明确时，先确认本次规划采用的目标。计划修订由用户显式运行 `to-plan`。

## 当前任务

`to-task` 根据当前项目的学习计划生成 `tasks/01-标题.md`、`02-标题.md` 等独立任务文件，每项围绕计划中的主要问题或产出组织。默认只保存为什么做、先做什么、留下什么、怎样判断完成，附预计投入区间和状态；多步骤、重要依赖或较高不确定性时才按需展开。判断或试错任务的反馈保存原先假设、结果差距与下一轮改变；重要能力按需检验迁移边界。实际耗时用于校准估计，记录在执行后追加，不预建空表。编号在项目内唯一且稳定，新增任务续号，保留已有编号与证据链接；已有单文件任务清单作为迁移输入保留原文。优先使用当前对话已明确的计划，已有文件按需参考；对话计划的相关目标与检验标准摘要保存在任务中，有实际文件时附链接。缺少计划或范围不明确时只补问关键内容，不强制其他入口或补建计划文件。

格式见 [to-task](learn/to-task/SKILL.md)。任务完成率不等于能力掌握。`/teach-me 01` 在已确定项目内定位编号任务，读取关联计划与证据后教学；只在证据满足验收条件时更新该任务状态，任务拆分或重排仍交给 `to-task`。

## 学习模型

`learn-modeling` 默认在当前使用目录建立材料模型或概念模型，用户明确指定保存位置时遵循其指定，保存实际覆盖范围、关键关系、边界、难点和来源导航。它区分来源内容、补充解释、学习者假设与未知，不保存掌握结论。

`grill-with-learn` 仅在指定材料阻塞判断时复用建模；`strategyfinder` 仅在材料理解阻塞战略判断时复用，将模型链接为决策卡依据，战略结论仍只记在卡中；`teach-me` 可在教学所需内容缺失时复用。格式见 [MODEL-FORMAT](learn/learn-modeling/references/MODEL-FORMAT.md)。

## 教学状态

`teach-me` 读取内部完整的 [官方 teach](learn/teach-me/references/teach/SKILL.md)，维护 `RESOURCES.md`、`lessons/`、`reference/`、`GLOSSARY.md`、`NOTES.md`、`assets/` 与 `learning-records/`。官方正文中的工作区指本次调用 `teach-me` 已定位的学习项目根，格式文件相对内部副本解析。

学习画像 `LEARNER-PROFILE.md` 只保存会改变下一节课的活跃教学决定；持久理解、纠正和独立表现保存在学习记录。画像格式见 [LEARNER-PROFILE-FORMAT](learn/teach-me/references/LEARNER-PROFILE-FORMAT.md)。

教学中用可检查目标、独立展示和反馈检验掌握，不因阅读完成或复述流畅就判定已会。教学发现的计划或任务调整建议交回对应显式入口；本次教学不自动重排整体计划或修改长期战略。

## 归档状态

历史 `reviews/`、十二周周期记录、协作画像和知识库规则可作为用户已有资料按需读取，但不再由当前 MVP 的独立入口创建或维护。退役入口与格式见 [deprecated](deprecated/README.md)，不要求删除用户已有工件。
