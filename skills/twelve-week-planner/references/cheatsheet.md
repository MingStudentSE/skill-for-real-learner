# 决策规则速查 — 十二周工作法：母书与写作应用手册

| 能力 | 一句话规则 |
|---|---|
| 五层执行闭环与症状路由 | 先定位愿景、计划、过程控制、记分或时间利用哪一层失效，再选工具。 |
| 12 周独立执行年 | 把十二周当作有独立截止、结算和重启权的一整年，不向年末借时间。 |
| 愿景阶梯到当前项目 | 从完整生活愿景倒推近景和当前项目，不为与愿景冲突的目标优化战术。 |
| 描绘当下与周期目标选择 | 只精确规划当前可预测的项目块，再用依赖、动量和容量选 1–2 个周期目标。 |
| 目标—战术—周次编译器 | 从最高杠杆战术依次加入，足以达成目标即停止，并为每项动作标频率或截止周。 |
| Model Week 日历容量证明 | 先把计划装进真实日历；纸面放不下就减量，不能把缺口交给意志力。 |
| 每周执行回路 | 每周先记分，再抽取本周战术、校验日历并执行日检；不要从杂务清单开始。 |
| 三层记分与四象限诊断 | 分开看战术执行、事前投入和事后结果，再决定修执行、修策略、删伪战术或保持。 |
| 4+4+4 节奏与周期内变更控制 | 先识别阶段与事件类型，再按最小改动原则等待、探索、移动、缩小或重启。 |
| 第 13 周双回路结算 | 第十三周分开结算结果与系统能力，庆祝和恢复后再写下一周期。 |
| 承诺代价门与可控行动 | 答应前核算结果、关键行动和真实代价；答应后只承诺约束下可控的下一步。 |
| 多项目串行聚焦与预写切换规则 | 先强制排序并尽量串行；必须并行时分配项目专属时间块并预写切换条件。 |
| 团队单一责任人与契约化周会 | 目标可以共享，战术必须单一负责；周会按契约只处理分数、依赖、障碍与下一步。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
