# 学习闭环

本参考层定义 `teach-me` 中选择学习块、暂停输入、验证理解和调整下一步的判断。概念本身的定义、机制与安全要求仍以可靠领域资料为准；遇到最新事实、专业规范或安全判断时，先查权威一手来源。

## 核心判断

### 0. 用三区判断定位理解边缘

从学习者有证据的当前理解通向目标理解。对每条会改变下一节课的活跃知识分支，只做一项教学决定：

- **已掌握 → 跳过**：独立解释、判断或应用的表现已足以支持当前目标。只在间隔检索、迁移检验或新任务需要时返回。
- **前置断层 → 补桥**：目标步骤依赖的概念或关系尚未具备，表现为记结论、猜答案或模仿操作。下一块只搭当前需要的最小前置桥梁。
- **理解边缘 → 教学**：学习者尚不会，但已有前置知识足以让其经过努力推导、解释或应用。下一个最小学习块放在这里。

“待探测”是证据状态，不是第四个教学区域。先复用学习记录、作品、复盘与当前表现；学习者自述和选择题作为待验证假设。只剩决定性缺口时，每次做一个区分性探测。每个学习块之后用讲回、判断或应用重新校准：充分证据使理解边缘前移，断层证据使下一步转为补桥。

### 1. 用基本问题选择材料

从期望和现实的差距写出一个可观察的问题，而非从“我想学 X”开始。例如，将“学 Kotlin”收窄为“我需要读懂并修改车辆设置页的状态更新，却无法判断何时该用不可变集合”。

选择内容时问：

1. 下一步真实行动是什么？
2. 哪个概念或关系正在阻碍这一步？
3. 哪些少量知识足以先做出一次可验证的尝试？

逐项检验必要性：缺少这个概念或关系，当前目标还能完成吗？可由其他知识覆盖或暂不影响目标的内容延后。单课通常聚焦 1–3 个概念；必要前置超过容量时拆课，保留各块之间的依赖关系。

成熟领域先采用可靠来源中的框架，再结合当前问题训练和内化；现有框架无法解释时，标明未知与假设，探索、验证后再提炼。个人重述用于表达理解，领域定义仍以可靠来源为准。

### 2. 对关键概念做到一字一义

只对高频、高杠杆或容易混淆的概念慢下来。每次澄清至少写清：

| 项目 | 要回答的问题 |
| --- | --- |
| 通用定义 | 在可信来源或领域中，它通常指什么？ |
| 边界 | 它不是什么；何时不适用？ |
| 当前语境 | 它在学习者的真实问题中改变哪个判断？ |
| 个人表述 | 学习者能否用自己的案例重述，而不偷换概念？ |

允许学习者形成贴近自身问题的“原创定义”，但不能把它伪装成通行定义或原作者观点。

### 3. 维护对知识的诚实

每个重要断言使用恰当标签：

- **来源事实**：材料、代码、数据或权威资料直接支持。
- **教学解释**：为帮助理解作出的简化、类比或推导。
- **学习者假设**：尚待行动或额外资料检验的判断。
- **未知**：当前没有足够证据，不能假装理解。

把“说得顺”与“确实会做”分开。缺少证据时，缩小问题、找出处或设计实验，让下一步直接填补空白。

### 4. 在能改变判断或行动处暂停输入

遇到可能影响行动的观点时，暂停继续读或继续讲。从以下问题中选择：

1. 它究竟解释了我生活或工作中的哪个现象？
2. 它与我已经见过的什么案例、概念或错误有关？
3. 如果它是真的，我下一次会做出什么不同判断或行动？

从中选择一个会推进当前目标的问题，等待回答。联系案例后，进一步核对学习者是否能说明相关机制和适用条件：什么因素通过什么关系影响结果，为什么这个解释适用于当前情境？只要求当前目标所需的深度；机制、影响因素或目的已阶段性澄清，足以支持下一判断时，转入展示或实践。

### 5. 用讲回和刻意练习制造证据

优先让学习者完成以下一种最小展示：

1. **解释**：不看材料说清概念、边界和因果。
2. **判断**：在给定输入中说明选择哪种方法及理由；也可说明为何暂不采用，指出不满足的适用条件，以及什么新证据会改变判断。
3. **迁移**：在一个相近但陌生的真实场景中完成行动。

按目标选择主动检索、辨析、解释或迁移，说明练习要检验的关系，并给出及时反馈，指出错在概念、关系、条件还是执行。难度以学习者能利用已有知识推进为准；无法推进时缩小任务、提供示范或补桥，再按提示程度记录表现。

实践技能可将一个完整而小的真实示范作为首段教学：在尝试前提供最低必要知识，呈现关键选择及理由，再让学习者尝试相近任务，针对卡点补充解释。模仿完成与独立完成分别记录。补桥或更换示范仍计入当前核心误区的重试轮次，达到入口停止线时结束当前块。

### 6. 把反思变成假设校正

复盘一件已经发生的事，按可观察结果校正假设：

| 顺序 | 问题 |
| --- | --- |
| 结果 | 发生了什么？可观察证据是什么？ |
| 原假设 | 当时认为什么会导致这个结果？ |
| 差距 | 预期和结果哪里不同？ |
| 修正 | 哪个假设、概念或条件需要改变？ |
| 下一步 | 用什么更小的行动检验新假设？ |

优先保留能跨场景解释、且可被进一步检验的假设；单次结果继续作为待验证线索。

对未来会反复使用的知识，在现有学习记录中按需写明下次调用情境、要支持的判断及反馈信号。后续会话遇到该情境时，先做一次最小检索或迁移，再决定是否补课。当堂达标只证明当堂展示的范围；跨时间、跨情境的表现分别积累。临时解决问题的知识可保留出处供查询，复习投入按未来用途决定。

## 每轮教学画布

在脑中按以下顺序组织本轮，不必默认写成文件：

```text
基本问题
  → 下一步行动
  → 必要知识及依赖关系（按单课容量拆分）
  → 概念边界 → 相关机制 → 有条件的判断
  → 学习者讲回／判断／迁移
  → 适用时实践验证（预期、信号、回看时间）
  → 结果驱动的唯一下一步；长期知识按需留下调用情境
```

一次只推进一个学习块、问一个问题。复杂材料先完成必要的结构梳理；本闭环只负责将其中当前最重要的一块变成判断和行动。

## 常见反模式

- **低水平勤奋**：把阅读时长、课程数量或笔记篇数当成学习成果。
- **模型收藏**：列出很多模型，却没有特定问题、适用条件或行动实验。
- **不懂装懂**：把假设、类比或熟悉感说成知识和掌握。
- **贪多求全**：没解决当前阻塞点，先搭一张庞大的知识体系。
- **脱离反馈的练习**：反复做熟题，既不暴露错误，也不改善判断。
- **伪复利**：把任何长期重复称为复利，不检查方向、反馈和不失败的底座。
