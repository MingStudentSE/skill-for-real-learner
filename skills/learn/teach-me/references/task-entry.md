# 项目与编号任务衔接

## 定位当前项目

先读取根 Agent 指令与其配置指针，按配置区分 workspace 公共目录和 project 学习状态目录；路径基准遵循配置，默认任务目录为当前 project 下的 `tasks/`。根据用户明确指定的项目、当前目录所属项目或本轮已明确且仍有效的项目上下文确定 project。根目录多个项目、信息冲突或无法判断时，只问要使用哪个项目并等待，不以最近修改时间或相同任务编号猜选。单一项目可从配置或已核对的项目工件确认；未配置时不要求先 setup。已有命名和布局继续使用。

内部官方教学正文中的工作区按当前 project 执行；workspace 的公共材料只有配置明确共享时才引用，教学状态始终留在当前项目。学习画像默认位于当前项目根目录，按配置映射。

## 解析 `/teach-me 01`

将纯数字参数视为编号请求，在唯一项目的实际任务目录按完整编号匹配 `01-*.md`，不以子串把 01 匹配为 010 或 101，不跨项目搜索后自动选择。沿用已有编号写法，不擅自改名或重编号。只有一个匹配才继续；多个同号文件、编号不存在或旧清单无法唯一映射时，说明问题并询问，不创建替代任务、不自动选下一号。用户指定完整任务路径时仍核对它的所属项目。

读完整任务、关联计划目标与验收、相关依赖、既有课程和证据，恢复真正未完成的部分。依赖有未满足且影响当前学习的验收时，说明阻塞并询问如何处理，不把前置任务直接标完。已完成任务可按用户要求复习或迁移检验，不清空原证据、不自动转入下一编号。

普通能力、概念或真实问题参数仍允许独立教学，不要求先有计划或任务；项目归属不明确时先询问。显式编号找不到时保持编号请求，不能降级为泛化讲解。

## 教学与状态更新

根据任务验收选择本轮最小学习块，保留 teach-me 的校准、一次一问及停止线。任务可以跨多课、多会话；本课达标不代表整项任务达标。

结束一个学习块时依次完成：

1. 保存课程，并在当前项目学习记录中写入实际表现、提示程度、结果和证据边界；只有持久理解或修正才形成持久掌握结论。
2. 在当前任务的教学与验收记录中写入实际课程及证据的相对链接，逐项标明已满足和未满足的验收、待复习项和唯一下一步；从各输出文件所在目录计算链接。
3. 依据证据更新该任务状态：开始学习为进行中，证据待核对可为已收集证据，核心缺口仍在为需补强；全部任务验收已有充分证据才为已完成。读过材料、课时结束、用户说懂了或只有本课局部目标达标均不足以标完。

保留任务编号、依赖、验收、自定义和原记录。验收或计划需要改变时只记录建议，交给用户显式运行对应规划入口；不自动重排、拆分、重编号或开始下一任务。
