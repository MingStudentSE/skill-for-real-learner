# teach-me

## 官方教学副本

官方 `teach` 正文及配套格式完整保存在 [references/teach/SKILL.md](references/teach/SKILL.md)。来源：[mattpocock/skills 的 teach](https://github.com/mattpocock/skills/tree/5beb35b040e3de97e54fa9e386d7e42d15c295c2/skills/productivity/teach)，同步提交：`5beb35b040e3de97e54fa9e386d7e42d15c295c2`（2026-10-24 核对 main）。更新时按固定提交完整同步五份教学正文与格式文件，保留原文。

开始前完整读取内部 [teach 正文](references/teach/SKILL.md)，执行其中的工作区、使命、课程、资源、参考资料、术语表、学习记录、笔记和资产契约，再读取[学习闭环](references/learning-loop.md)。内部正文提到的 `/teach` 工作区均指本次 `/teach-me` 的用户学习工作区；直接读取正文，不启动另一个 skill。

先读取根 `AGENTS.md` 的配置指针及其指向的本地学习配置；默认位置为 `docs/agents/learning.md`。按[项目与编号任务衔接](references/task-entry.md)解析 workspace（工作空间根）、project（当前学习项目根）和可选编号任务，完成唯一定位后再教学。workspace 级路径相对工作空间，project 级路径相对当前项目，已有配置的路径基准优先。无配置仍可在明确的当前项目直接教学。内部 `/teach` 工作区在多项目布局中映射为当前 project；使命、课程、资料、资产、画像和其他教学状态都归属当前项目，沿用已有布局。只有内部 `*-FORMAT.md` 链接相对 `references/teach/` 解析；本包装器参考链接相对本 skill 解析。状态不得写入 skill 安装目录或其他项目。

只在首次创建学习画像，或新证据改变画像中的教学决定时，阅读[学习画像格式](references/LEARNER-PROFILE-FORMAT.md)并写入。内部官方正文定义基础教学行为；本文件定义工作区映射、学习闭环与共享计划的衔接。

## 运行教学闭环

1. **恢复当前语境。** 读取当前项目已有 `LEARNING-PLAN.md` 和已定位任务文件（默认 `tasks/01-标题.md`）中与本轮相关的目标、依赖、进度与验收要求，再读取与当前问题直接相关的 `MISSION.md`、`LEARNER-PROFILE.md`、学习模型、学习记录、复盘或任务，只补问现有工件未提供的决定性信息。**本步完成：** 已明确本轮真实问题、当前表现、现有证据与待验证项；缺少其中一项时，只问一个问题并等待。
2. **校准理解边缘。** 只列出会改变下一节课的活跃知识分支，按学习闭环的**三区判断**与探测规则处理。**本步完成：** 每个活跃分支都有教学决定；还有决定性缺口时，只问一个区分性问题并等待，将回答分类后才进入下一步。
3. **选定最小学习块并立本课目标。** 按学习闭环从真实问题倒推不可缺少的概念与关系；单课通常聚焦 1–3 个概念，必要前置超出容量时拆课并保留关系。有可靠框架时先借助框架训练和内化；尚无适用解释时标明假设，探索验证。教学前展示并在本节课程工件写入一条可检查的**本课目标**：学习者要在什么情境下、不看材料完成哪一种解释、判断或迁移，以及什么表现算达标。目标包含用自己的话重建核心关系及一次与当前问题相关的最小展示；判断可以是有理由地暂不采用。**本步完成：** 只有一个下一学习块；目标、必要知识及达标证据已明确；练习要促进的检索、辨析、解释或迁移，以及退回补桥信号均已写清。
4. **围绕一个步骤教学后暂停。** 运行内部正文的讲解与练习，按学习闭环澄清关键概念、相关机制和适用条件。概念学习可先讲解再检验；实践技能可用含最低必要知识与关键理由的小示范作为首段教学，再尝试相近任务，针对卡点补充解释。让学习者自己说明知识如何支持当前判断，或完成一次尝试，然后等待回答。**本步完成：** 已获得学习者自己的解释、判断或操作；联系个人案例只支持其实际展示的理解，按第 5 步核对目标。
5. **用本课目标停止。** 先判断第 4 步的无提示表现是否已覆盖本课目标，只对缺少的达标证据再做一次最小展示，并按学习闭环校准理解边缘。**停止线：** 本课目标达标时，立即结束当前学习块，只总结达标证据、证据边界和唯一下一步，等待学习者明确要求后再开始新的学习块。次要表述修正记入反馈，不扩张本课目标。同一核心误区最多进行两轮“反馈 → 重试”；两轮后仍不稳定时，标为待复习并结束当前学习块，下次更换解释或练习。下一步服务当前目标，可为真实尝试、补充证据或在明确条件下暂不采用；已经完成迁移时直接记录结果。对值得长期使用的知识，在现有学习记录中按需留下下次调用情境和反馈信号。**本步完成：** 当前学习块已达标或已转为待复习，且状态、表现证据、证据边界和唯一下一步均已记录。
6. **更新画像与下一步。** 首次校准完成后创建 `LEARNER-PROFILE.md`；新证据改变教学决定时，按格式就地更新并裁剪画像。持久理解、误解修正或先验知识另写入 `learning-records/`。回看时按“结果 → 原假设 → 差距 → 修正假设 → 下一步”反馈。**本步完成：** 画像与最新证据一致，且只留下一个下一步。

## 复用学习模型

本轮以用户指定的书、文章、视频或课程讲义为主要来源，而已有学习模型尚未覆盖教学所需范围时，调用 `/learn-modeling` 建立最小必要章节的模型。读回模型路径、已覆盖范围、概念关系和来源定位后继续教学；把模型作为教学输入，用学习者的独立表现另行产生掌握证据。

课程讲解、来源核对或练习需要使用学习工作区 `reference/` 内的电子书时，先按配置定位课程、资料与资产，从实际课程输出文件所在目录计算 HTML 相对链接；下述默认路径仅作示例。在对应 `lessons/*.html` 的相关表述或阅读动作处加 HTML 超链接，直接打开实际用到的 PDF 页，例如 `../reference/<书名>.pdf#page=78`；不得只链接整本文件再让学习者自行寻页。链接文案写明使用的单页或页码范围，`#page=` 使用当前 PDF 文件中能实际跳转的页序；多个不连续位置分别链接。完成课程前验证目标文件存在，且链接带有对应页码片段。

本入口服务跨会话的持续学习。`LEARNER-PROFILE.md` 只保存当前教学决定；`learning-records/` 保留持久证据，`NOTES.md` 保留稳定教学偏好。画像通过链接引用两者。共享计划使用当前项目的 `LEARNING-PLAN.md`，任务默认分文件保存在 `tasks/`，按已有配置定位；旧单文件清单保留，不自动迁移。按[项目与编号任务衔接](references/task-entry.md)先保存课程与持久证据，再在当前任务记录证据链接、已满足及未满足的验收和唯一下一步，最后更新状态。单节课目标达标只证明该学习块；全部任务验收均有充分证据时才标记任务已完成。没有计划或任务时仍可围绕明确问题直接教学，不预造空文件。计划范围、优先级或验收需要修订时，记录建议交给用户显式运行 `/to-plan`；任务需要拆分或重排时交给 `/to-task`，本轮不改写验收、不重编号、不自动进入下一任务。

一次只问一个问题。每轮结束时，用一两句话说明已得到的证据、尚未验证的假设和唯一下一步。

## 完成条件

本轮以第 5 步停止线为完成条件。结束时，学习者拥有：一个被澄清的真实问题、一份已创建或确认仍有效的学习画像、一条明确的本课目标、该目标已达标或转为待复习的表现证据，以及一个已记录的可观察下一步。
