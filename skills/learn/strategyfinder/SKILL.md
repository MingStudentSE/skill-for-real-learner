# 学习战略寻路

以 `/grilling` 为主干，帮助学习者从实践中发现值得投入的方向，再用反馈校正判断和资源配置。让学习者先提出判断与依据，Agent 负责追问、核对证据和揭示机会成本；取舍与投入承诺由学习者作出。

## 适用边界与工作区

仅在学习者主动审视长期方向、重大精力配置或继续已有战略时运行。普通课程、单次任务和日计划交给相应学习流程；短期表现波动先作为证据保存。

若工作区根 Agent 指令提供学习配置指针，读取所指配置；否则检查默认位置 `docs/agents/learning.md`。没有配置时沿用已明确的目录与已有战略工件，确认没有同用途工件后才使用默认名称；工作区或工件归属不明确时询问。配置缺失不阻塞运行，也不自动创建配置。

维护同一张长期战略地图 `STRATEGY-MAP.md` 和必要的 `strategy-decisions/` 决策卡，按配置映射实际位置。读取 [地图与决策卡格式](references/map-format.md) 后写入；产物保存在用户工作区。决策卡只记录需要跨会话跟进的关键问题，小问题直接在当前对话解决。

## 1. 读取实践证据

读取当前目标相关的笔记、时间记录、任务、产出、反馈与既有战略；额外资料库只在用户明确提供位置或授权后读取。区分事实、自述、推断和未知，保留来源与时间范围。

围绕候选方向整理：

- **投入**：实际时间、金钱、精力，以及被挤出的其他机会；计划投入与实际投入分开。
- **结果**：完成的作品、解决的问题、用户反应、收入或其他与目标相关的变化。
- **沉淀**：形成的能力、可复用资产、关系或选择权。
- **持续性**：能量变化、重复交付成本与现实约束。

只比较可比场景，说明样本量、反馈延迟和替代解释。回报包括与学习者目标有关的非金钱收益；证据不足时使用区间或定性判断，不编造 ROI 数字。没有记录时，将缺口说明为未知，用一次真实行动开始积累证据。

完成条件：能指出当前实际投入去了哪里、产生了什么，以及哪些判断仍缺证据。

## 2. 质询目标与取舍

加载 `/grilling`，沿其分轮访谈方法推进当前判断，不另设固定问卷。围绕学习者的回答追问：当前最想改变什么，为什么值得投入，有什么已有优势和真实需求，选择它将挤出什么，什么结果会改变判断。

从记录中寻找反馈较好且能够重复的点。方向不清时，先形成少量可测试的候选；通过小范围实践筛选，再将有效做法连接成可重复路径，逐步扩大投入。明确长期方向时，将其作为当前证据支持的方向记录，允许新的实际结果推动修订。

比较长期方向、重大投入或高不可逆选择时，读取 [战略判断镜头](references/strategic-lenses.md)，选取最关键的一到两个未知，检查不失败底座与复利假设。

只有用户指定材料、概念或笔记的理解阻塞当前判断时，加载 `/learn-modeling`，建立最小必要模型并链接来源。模型保存位置遵循建模技能的保存规则；个人偏好与战略结论保存在决策记录中。

完成条件：学习者已表达当前判断、机会成本，以及决定下一步投入所依赖的关键假设。

## 3. 补证据与设计低成本测试

先判断缺口属于哪一种，再选择最小动作：

- **价值或承诺不清**：继续质询，由学习者确认取舍。
- **外部事实未知**：只查会改变取舍的事实，优先一手来源，记录适用日期、范围与冲突。简单事实可直接引用；复杂调查按需要委派或留下笔记，不强制使用特定研究流程。无法核实时保留未知。
- **实际效果未知**：设计一次真实测试，例如小范围服务、报价、作品发布、访谈或真实工作任务。需要软件原型时再选择适用工具与流程；演示只能验证其实际覆盖的问题。

每次测试只针对一个关键假设，明确目标对象与场景、最小行动、时间与费用上限、观察信号、复盘时间、停止或缩小条件。兼顾失败时损失可承受，以及成功后能否重复；有必要时通过多次小测试验证，避免用单个偶然结果直接推断长期价值。

让学习者说明预期结果及其对应的投入决定，再记录测试安排。实验计划、模拟结果或口头兴趣都不能替代它们未覆盖的真实行为证据。测试设计完成后等待实际结果；外联、付费、发布和真实实现修改按已有明确授权执行。

完成条件：当前缺口已有足够证据，或已定义可执行且成本可控的验证动作；后者保持待验证。

## 4. 根据反馈调整资源

用户带回结果时，对照测试前的预期、实际投入与观察信号复盘：哪些假设得到支持，哪些被反证，是否存在执行、样本或环境因素。先请学习者判断下一步，再质询依据。

由学习者选择加码、维持、缩小、转向或暂停，明确下一阶段分配多少时间、精力或预算，以及相应减少什么。加码须说明支持证据、护栏和下次复盘条件；结果不确定时保留假设，缩小验证范围。

只有问题对应的证据和学习者取舍齐备时才关闭决策卡。放弃方向也可关闭；明确区分实验已完成与战略假设已被证明。重大的方向修订保留旧方向、新方向、原因与证据。

## 输出与交接

首次建图时，保存当前方向或候选、资源配置原则、实际投入摘要与关键未知；只为值得跟进的问题建卡。继续已有战略时，优先推进用户点名的问题，否则选择无未解决依赖的关键卡。每次聚焦一个战略判断，必要的事实核查可并行。

地图保存低分辨率结论，卡保存依据、验证安排、实际结果和取舍。结束时说明当前判断、下一步验证或资源调整、等待什么反馈。没有待解决的关键问题时，说明“当前阶段路线清晰”。

学习计划、任务拆分与教学由用户显式选择相应入口；执行中的新证据在用户下次主动调用本 skill 时回流，不自动改写战略。
