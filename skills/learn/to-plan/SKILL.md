# 定制学习计划

与学习者一起澄清目标、讨论实际条件和方案，按反馈调整，取得对具体方案的明确同意后再生成正式计划。接受模糊的学习意图，也接受已有目标或计划；规划跨度服从目标，长期成长保留远期路线，近期问题可以用较短的阶段计划。

## 读取学习状态

先按用户工作空间根 Agent 指令中的指针读取本地学习配置；默认位置为 `docs/agents/learning.md`。先定位当前学习项目：用户明确指定 → 当前目录所在项目 → 当前对话已明确且未被本次路径覆盖的项目 → 唯一项目；多个候选无法确定时只询问项目。首次建立项目时明确目标文件夹后再写入，不把工作空间根默认当作新项目。以下文件名均相对该项目根，并映射到配置中的实际位置；已有根项目与自定义布局保留，不另建同角色副本。共享战略资料按配置中的工作空间路径读取，不借用其他项目的使命或计划。

阅读当前对话，以及已有的 `STRATEGY-MAP.md`、已关闭的 `strategy-decisions/`、`MISSION.md`、`RESOURCES.md`、`LEARNING-PLAN.md` 和相关 `learning-records/`；仅在工作区存在 `CONTEXT.md` 时读取它。复用已明确的目标、约束、术语与能力证据，避免重复访谈；战略、使命文件和前置质询都不是制定计划的必要条件。

## 澄清目标与用户情况

先综合已知信息，只补问会改变目标、范围或路线的缺口。每轮集中处理最关键的少量问题，等待回答后再推进依赖它的决定；不要把整份信息清单一次性交给学习者填写。

1. **搞清楚目标**：明确为什么现在学、准备在哪些场景使用、希望做到什么程度，以及怎样算达到目标。有期限时明确期限；兴趣探索可以以完成体验、形成判断为目标，无需强加职业化或变现要求。把“学 Python”这样的主题转成具体用途和可观察的成功表现。
2. **了解实际情况**：核对已有基础和尝试、当前卡点、可持续投入的时间与精力、预算、资源与工具访问条件，以及影响执行的偏好和阻力。区分已展示的能力、自述熟悉度和未知；只有起点的不确定会改变路线时，才请学习者提供一个相关实例或简短表现，不在此展开教学。
3. **处理目标与条件的冲突**：说明在现有投入下的取舍，提供缩小范围、延长期限或增加必要支持等可行选择，由学习者决定。保留非阻塞未知与暂定假设，在首个检查点验证，不虚构基础或承诺达成时间。

完成条件：能够说明学习者为什么学、在哪个场景做到什么、用什么表现判断成功，以及哪些个人条件会改变计划。缺少其中决定路线的信息时继续澄清；信息已充分时进入方案讨论与确认。澄清限于本次学习目标，不替学习者决定整个人生方向，也不自动启动其他用户入口。

## 共同讨论并确认方案

对话已明确学习目标和用户情况时，提出简明、可供讨论的方案建议，说明范围、路线、学习方式、实际投入与第一个检查点，并解释个人条件如何影响这些选择。主动请学习者反馈是否做得到、哪里负担过重、需要怎样调整；按反馈迭代方案。战略、使命文件及前置质询均非必要条件；缺少它们时不补建，也不要求用户先运行其他入口。已有战略或使命仅作相关背景参考，计划自身写清学习原因、成功标准与约束，不依赖教学入口的内部格式。

对话中的目标与已有资料冲突且尚未明确取舍时，只确认影响本次计划的差异；已明确的决定纳入讨论方案。保留原战略与使命文件，除非用户另有明确修改要求。

确认学习者明确同意当前具体方案后，才生成或更新正式计划；确认问题应指向已经展示、可供判断的方案。目标和个人信息齐全、用户启动本 skill 或泛泛说“帮我制定计划”，均不等于同意尚未讨论的方案。未获同意时停留在讨论建议，不输出完整正式计划，也不创建或覆盖计划文件。已有对话中对同一方案的明确同意可直接沿用，无需重复确认；同意后若范围、投入或方法发生实质变化，先讨论变化并重新取得同意。修订已有计划同样适用。

## 编写学习计划

先阅读 [计划格式](references/plan-format.md)，再创建或更新 `LEARNING-PLAN.md`。围绕“现实问题 → 目标能力 → 必要知识 → 练习场景 → 验收证据”组织以下决定，并说明个人条件如何影响选择：

1. **范围与深度**：从真实差距确定当前核心问题，选出最小必要的概念、模型、案例或前置技能；每项说明用途与所需深度，如了解、独立运用或深入理解机制与边界。为值得长期使用的基础安排深入学习，其余按用途取舍。
2. **路线与方法**：按能力依赖安排阶段，写明目标能力、进入条件、练习场景和可观察产出。实践技能安排观察示范与动手使用；理解性目标安排概念、机制、关系与边界的探究；考试目标按考查要求安排练习。按需要组合，说明为何适合此人，不把同一学习方法套给所有领域。
3. **资源与支持**：选择服务目标的可信主资源，说明用途与访问条件，暴露资源缺口；按需加入案例、反馈者或实践环境，不强制参加社群，不编造权威来源。已有 `RESOURCES.md` 时引用其中资源。
4. **可持续节奏**：把可用时间、精力和主要执行阻力落实为阶段大小、练习频率、反馈与巩固循环，说明投入不足时如何缩减。远期保持粗粒度，当前阶段写清如何开始、如何练习及预期产出，详细程度服从学习者的执行需要。
5. **检验与调整**：按能力簇、真实任务或有意义的一段练习设置检查点，写明独立表现、解释、迁移或真实反馈的证据、通过条件和未达标时的调整。将能力证据与受外部因素影响的现实结果分开；阅读量和熟悉感不能代替掌握。复盘同时关注效果与执行成本，明确何时继续、补基础、调整方法或缩小阶段。
6. **可复用积累**：按目标选择有后续用途的案例、作品、判断标准、操作方法或知识连接，说明以后如何再次使用；无需为每项学习另造文档。

## 输出

交付或更新 `LEARNING-PLAN.md`，概述澄清后的目标、用户情况如何影响计划、当前阶段、第一个检查点与未解决假设。交付可独立使用的计划后即完成本次规划。

完成条件：学习者已同意所采用的具体方案，计划与该方案一致；计划自身写清目标、成功标准与约束，且计划的范围、深度、路线、方法、资源、节奏和验收均能追溯到学习目标与用户情况；学习者能够据此开始行动、检验进展，并在效果不佳或负担过重时调整。
