# Ask Ming

根据学习者的问法决定讲多深。给出能直接复制的命令，把示例里的主题、材料和时间换成对话中已有的信息。下一次调用由学习者自己发起。

- **想看全貌**：按下表介绍各入口。用一个主题串起可选路径，例如先选学习方向，再制定计划、拆任务、按编号上课。同时演示如何从一个具体问题直接开始教学。
- **点名问用法或区别**：说明什么时候选它、需要带什么信息、调用后会发生什么。比较两个入口时，用同一个学习场景分别写出命令，让学习者从想得到的结果判断。
- **带着问题来选**：先判断眼前需要的结果，给一个首选入口、理由和示范命令。如果材料相同但用途不清，只问一个能改变推荐的问题，例如“你想先拿到一份能回查的笔记，还是希望有人出题检验你是否理解？”

| 想得到的结果 | 可以怎么问 | 调用后会发生什么 |
| --- | --- | --- |
| 选值得投入的方向 | `/strategyfinder 我在数据分析和产品设计之间犹豫，每周能拿出四小时，怎么试出哪个值得继续？` | 回看实践与投入，找出关键假设，设计一次低成本测试。 |
| 为明确的目标做计划 | `/to-plan 我只会筛选和排序，希望四周后能独立分析销售表，每周三小时。` | 讨论起点、资源和检验点，同意方案后才保存计划。 |
| 把已有计划拆成任务 | `/to-task 按刚讨论好的销售分析计划，把第一阶段拆成能验收的任务。` | 沿用当前对话或已有计划，在项目里生成编号任务。 |
| 学懂一个问题或练习任务 | `/teach-me 为什么汇总各组的平均数时要考虑组内人数？` | 从具体问题开始讲解与练习，用独立表现检验理解。项目里已有第 01 项任务时，也可输入 `/teach-me 01`。 |
| 整理能回到来源的材料笔记 | `/learn-modeling 根据我附上的销售分析讲义，梳理第三章的指标、适用条件和例子。` | 整理指定范围的概念关系、难点和来源位置。 |
| 澄清一个学习问题，必要时对照材料 | `/grill-with-learn 对照我贴的岗位要求，追问我这次到底要学会什么。` | 逐轮澄清学习问题，指定材料妨碍判断时再对材料建模。 |
| 质询一般计划或决定 | `/grill-me 我准备把周报从周一改到周五，帮我检验这个决定。` | 用逐轮追问检验假设和取舍。 |
| 了解或直接使用质询方法 | `/grilling 逐个追问我对周报读者的假设。` | `grilling` 提供逐轮质询方法，`grill-me` 是调用该方法的简便入口。两者都可点名。 |

只讲解用法，停在学习者能发出下一条命令的位置。回答用法通常只需当前对话。学习者询问本机能否运行时，再核对当前环境可见的入口，将已发布与此处已可用分开说明。用户问到本导航自身时，用 `/ask-ming 我手里有一章讲义，该用哪个 skill？` 示范。
