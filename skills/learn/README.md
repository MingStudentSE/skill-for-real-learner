# Learn

本项目维护的学习能力。调用分类、产出与当前发布清单以 [skills 总索引](../README.md) 为准。

## User-invoked

- [setup-learn-skills](setup-learn-skills/SKILL.md)：配置本地学习环境。
- [grill-with-learn](grill-with-learn/SKILL.md)：质询澄清，指定材料阻塞判断时按需建模。
- [strategyfinder](strategyfinder/SKILL.md)：以 `grilling` 为主干，从实践及时间/金钱/精力投入与反馈分析候选方向，识别关键假设、按需查证并设计低成本真实测试；复盘后由用户决定加码、维持、缩小或暂停。维护战略地图与决策卡，仅在材料理解阻塞判断时加载 `learn-modeling`。
- [to-plan](to-plan/SKILL.md)：定制与修订学习计划。
- [to-task](to-task/SKILL.md)：在学习计划内安排当前任务。
- [teach-me](teach-me/SKILL.md)：持续教学、练习、掌握检验与记录。

## Model-invoked

- [learn-modeling](learn-modeling/SKILL.md)：指定材料与概念的内容建模。

用户入口由学习者显式启动，彼此通过工件交接。`strategyfinder` 不强制研究子代理或独立研究笔记。

来源维护：`teach` 副本保存在 `teach-me` 内部，research 与 prototype 副本暂按原字节保留在 `strategyfinder` 内部，作为可选资料，无强制运行依赖；均不新增公开入口，来源与许可统一见 [UPSTREAM](../../UPSTREAM.md)。
