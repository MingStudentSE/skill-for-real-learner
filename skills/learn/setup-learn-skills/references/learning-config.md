# 本地学习配置模板

生成到用户工作区 `docs/agents/learning.md`。以读取到的用户布局替换占位值；没有约定时才建议默认名称。此模板描述配置，不创建其列出的状态文件。

```md
# 本地学习配置

## 工作区与布局

- 工作空间：<已确认的根目录；项目目录相对该根目录>
- 项目布局：<默认根目录下每个学习项目一个文件夹；保留已有命名与嵌套结构>
- 已有项目：<已核对的项目路径；没有则标明尚未创建，不生成占位项目>
- 项目识别：<实际项目目录约定或已有项目映射；后续新增项目沿用该约定>
- 项目选择：用户明确指定 → 当前目录所在项目 → 当前对话已明确且未被本次路径覆盖的项目 → 唯一项目；多个候选仍无法确定时询问。
- 指令入口：<根 AGENTS.md 或已有权威入口；各项目继承，不新增重复指令文件>
- 现有命名约定：<保留的文件名、目录名、编号规则>
- 材料位置：<项目内资料目录；共享资料另标工作空间相对路径；无则标明未配置>
- 教学输出：<项目内 lessons/、reference/、assets/ 或对应目录>
- 学习模型：<项目内 learning-models/ 或对应目录>

## 项目内学习状态路径

下列路径均相对已选学习项目根；每个项目维护自己的使命、计划、任务与教学证据。工作空间级共享资料须另行标注基准，避免与项目路径混用。已有项目的自定义路径优先；新项目使用共同默认值。

| 用途 | 路径 | 创建时机 |
| --- | --- | --- |
| 长期战略地图 | <STRATEGY-MAP.md 或已有地图> | 用户显式审视长期方向时 |
| 战略决策卡 | <strategy-decisions/ 或已有目录> | 战略问题可明确表述时 |
| 统一学习计划 | <LEARNING-PLAN.md 或已有等价计划> | 学习者明确制定计划时 |
| 编号学习任务 | <tasks/ 或已有任务目录>；每项为 01-标题.md、02-标题.md 等 | to-task 根据已有计划拆解时 |
| 教学使命 | <MISSION.md 或已有使命> | to-plan 制定计划或 teach-me 明确真实目的后 |
| 可信资源 | <RESOURCES.md 或已有资源表> | 首次核实教学来源时 |
| 学习画像 | <LEARNER-PROFILE.md 或已有画像> | 首次校准获得证据后 |
| 持久学习证据 | <learning-records/ 或已有目录> | 产生持久理解或修正时 |
| 教学偏好 | <NOTES.md 或已有偏好文件> | 明确稳定偏好时 |
| 已掌握术语 | <GLOSSARY.md 或已有术语表> | 有独立理解证据时 |
| 复盘证据 | <用户已有复盘位置；无则由 teach-me 保存在相关教学记录中> | 有可检查表现或检查点时 |

以上为路径约定；尚不存在的状态保持不存在，由对应入口按需创建。

## 可用学习 skills

| 入口 | 本环境验证的位置 | 使用边界与调用方式 |
| --- | --- | --- |
| <实际可用 skill> | <已核对的安装位置> | <用户显式调用或模型按需复用；职责> |

只列实际可用的入口。用户入口由学习者显式选择，建议下一条命令后等待；不自动串联。

## 阅读与更新规则

- 开始学习任务前先读本配置并定位项目，再读当前目标相关的计划项、任务和最新证据；按需加载材料，不全量扫描所有历史，也不混读其他项目状态。
- 复用已有命名和目录；项目目录相对工作空间根，学习状态相对当前项目根，格式文件链接相对所属 skill 的参考文件。
- to-plan 保存项目计划；to-task 按计划生成 tasks/01-标题.md、02-标题.md 等任务，每个文件关联计划目标并保存行动与验收。编号在项目内唯一且稳定，新增任务续号，重排通过依赖和执行顺序说明。
- /teach-me 01 在已定位项目中精确匹配编号 01 的任务，读取关联计划与证据后开始或继续教学；缺失、重复编号或项目歧义时说明问题并询问，不跨项目猜测。
- 课程与学习记录保存表现证据并链接回对应任务；只有实际表现满足任务验收要求才更新为完成，覆盖内容和学习时长不等于掌握。
- 没有计划时可以直接教学；to-task 仍须先有计划。已有单文件任务清单保留，交由用户显式运行 to-task 时迁移，不在 setup 中复制或删除。
- 实质改变计划范围、优先级或已有布局时，展示具体草稿并确认；已有明确授权的具体配置直接执行。
```

管理边界：再次运行时以用户当前配置为准，逐项补缺，保留自定义章节和已确认路径。根指令只保留配置指针，详细规则在此文件维护。

## 当前发行版候选入口

按以下九项核对实际安装；将可用项及其实际位置写入用户配置。下列仓库相对链接用于维护时核对，不原样复制到用户工作区。不把内部官方 `teach` 或退役入口列为可安装技能。

| 入口 | 调用属性 | 职责 |
| --- | --- | --- |
| [setup-learn-skills](../SKILL.md) | User-invoked | 本地配置与阅读指针 |
| [grill-with-learn](../../grill-with-learn/SKILL.md) | User-invoked | 澄清学习问题，按需建模材料 |
| [strategyfinder](../../strategyfinder/SKILL.md) | User-invoked | 长期方向与取舍 |
| [to-plan](../../to-plan/SKILL.md) | User-invoked | 使命与统一学习计划 |
| [to-task](../../to-task/SKILL.md) | User-invoked | 在已有计划内拆分和安排任务 |
| [teach-me](../../teach-me/SKILL.md) | User-invoked | 教学、练习、掌握检验与记录 |
| [learn-modeling](../../learn-modeling/SKILL.md) | Model-invoked | 材料结构、概念关系与来源导航 |
| [grill-me](../../../up-stream/grill-me/SKILL.md) | User-invoked | 官方显式质询入口 |
| [grilling](../../../up-stream/grilling/SKILL.md) | Model-invoked | 可复用的分轮访谈方法 |

计划修订交给用户显式运行 `to-plan`，任务拆分或重排交给 `to-task`；掌握判断和教学内复盘由 `teach-me` 处理。没有计划时允许直接教学，`to-task` 仍要求已有计划。
