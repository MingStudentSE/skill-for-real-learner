# 学习建模

把一个指定知识范围转换成学习者能读懂、能回到来源、可供后续学习复用的学习模型。范围可以大到一本书，也可以小到一个概念；范围差异由内部格式处理，不增加用户入口。

开始前读取 [`references/MODEL-FORMAT.md`](references/MODEL-FORMAT.md)，按实际范围选择其中一种内部格式，不同时生成两份重复笔记。

## 锁定范围与来源

1. 读取用户指定的来源和当前已有模型；仅在工作区存在 `CONTEXT.md` 时读取它。来源可以是书、文章、视频、讲义、章节、笔记片段，或互动学习已经核实的资料。
2. 根据目标选择内部范围：
   - 用户要看懂来源的论述结构、章节关系或多个概念时，建立**材料模型**，保持原材料顺序。
   - 用户已经点名一个概念，想解释、整理或保存它时，建立**概念模型**，围绕基本问题、定义、边界、机制、关系和例子组织。
   - 一个宽泛主题、整节材料或多个并列概念不能伪装成概念模型；保留材料范围，或只在确实影响结果时请用户点名一个概念。
3. 长材料先读取目录并确定本次实际覆盖范围。没有实际阅读的部分只能标为待覆盖；搜索摘要、目录和记忆不能冒充来源内容。
4. 复用可靠的学习者起点。没有起点时，按具备一般阅读能力的零基础学习者解释，并把这项假定写入模型。

## 建立共同内容

无论范围大小，都完成以下工作：

1. **讲清对象。** 先用学习者语言说明它在解决什么问题，再解释必要术语、关键关系与结论。
2. **补足最小背景。** 只补读懂当前范围必需的前置知识；背景本身需要系统学习时，记录仍需补足的范围。
3. **说明边界。** 第一次出现的关键概念同时写清它是什么、在当前来源中有什么用、不要和什么混淆，以及何时不能推出当前结论。
4. **显出关系。** 使用紧凑的箭头、表格或层级表达依赖、组成、因果、对比或应用条件，不罗列无关系的名词。
5. **处理难点。** 对真正会阻塞理解的地方说明为什么难、人话解释、常见误解，以及一个能揭示关键条件的短例子或反例。
6. **诚实标注。** 区分原材料内容、补充解释、学习者假设与未知。来源本身的推断不能升级为事实，补充解释不能伪装成作者原话。
7. **保留导航。** 为重要内容记录章、节、页码、时间戳、路径或段落锚点；无法精确定位时明确写“来源定位待补”。

## 按范围深化

### 材料模型

按原材料章节或段落顺序建立内容总览，区分核心与延伸内容，说明每一部分与前后内容如何衔接。完整覆盖不等于逐句复述：保留重要论点、逻辑、案例作用和必要细节，删去不改变理解的重复。

材料模型中的单个概念只解释到足以读懂当前材料；只有用户明确把该概念设为当前建模范围时，才建立独立概念模型。

### 概念模型

从概念要回答的基本问题出发，写清通用定义、当前来源中的含义、最短机制、失效边界和 2–4 个必要关系。正例与易混淆反例应表面相近而关键条件不同，使学习者能看出这个概念如何改变解释或判断。

用户提供个人情境时，可以记录为“学习者情境/假设”，并写出可供尝试的 `输入 → 判断 → 行动`；这只是模型中的应用假设，不是已经发生的学习证据。没有用户情境时保留待补，不虚构个人经历。

## 写入与交接

默认在 `./learning-models/` 创建或更新 `<YYYY-MM-DD>-<topic>.md`。同一来源或概念的新覆盖范围、更准确解释与来源定位更新同一个模型，并记录修订原因；不要覆盖无关的已有文件。

`learn-one-concept` 在学习者选择保存时可以复用本 skill 建立概念模型。只接收已经核实的来源内容、教学解释和明确标注的学习者假设；学习者的讲回表现、反馈和掌握判断留在对话或学习记录中，不写进学习模型。

交给 `teach-me` 时，说明模型路径、范围、核心内容、前置知识与难点。学习模型不包含练习流程、任务计划、学习过程或掌握结论。

完成条件：范围与来源可核对；所选格式与范围一致；重要概念、关系、边界、难点和来源导航足以支持后续学习；来源内容、补充解释、学习者假设与未知没有混淆。
