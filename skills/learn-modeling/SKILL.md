# 对学习材料建模

把一份学习材料转换成学习者能读懂、能回到原文、可用于后续学习的学习模型。模型尊重材料的章节顺序，但不照抄：它补足读懂当前内容所需的背景，标出概念关系和难点，并诚实区分原材料与补充解释。

## 适用边界

当用户指定一份可访问的书、文章、视频、课程讲义或文件，并要求整理、总结、解释或建模时使用本 skill。

不要用本 skill 做以下事情：

- 记录学习者说过什么、做过什么或是否掌握。
- 追问、讲课、出题、练习或反馈。
- 决定学习使命、学习 SOP 或任务计划。
- 未阅读材料就宣称完整覆盖，或把目录、搜索摘要和记忆当成原材料内容。

## 确定材料与模型范围

1. 读取指定材料和 `CONTEXT.md`。材料是长书、长课或多篇资料时，先读取目录和当前模型，确定这次实际建模的章节范围。
2. 复用已有学习者起点；没有可靠起点时，按“对该材料零基础、具备一般阅读能力”解释。把必须补足的知识写入前置知识桥，不要假定学习者懂术语。
3. 为长材料先建立按章节排列的总览，并把“已建模范围”和“待覆盖范围”写清楚。只对已实际处理的部分标记为已覆盖。
4. 遇到 `CONTEXT.md` 没有的、会在多个模型中反复使用的领域术语，立即补入词汇表，写清它是什么和不是什么。

## 依章节建立模型

按 [`references/MODEL-FORMAT.md`](references/MODEL-FORMAT.md) 创建或更新模型。保持原材料的章节顺序；每个已覆盖章节至少包含：

1. 用学习者语言写出本章在讲什么，以及它与上一章如何衔接。
2. 标出核心内容和延伸内容。核心内容必须覆盖后续理解所必需的概念、关系和结论；延伸内容保留材料的完整性，但不与核心内容争抢注意力。
3. 用紧凑的箭头、表格或层级关系展示概念如何依赖、解释或推导。不要只列名词。
4. 在原材料对读者背景有要求时，补入最小的前置知识桥；背景本身大到无法短解时，说明仍需另行系统学习的范围。
5. 为每个真正的学习难点说明：为什么难、用人话怎么理解、常见误解、一个短例子或反例，以及它回到原文的位置。
6. 把每项内容标为“原材料内容”或“补充解释”。补充解释可以更口语、更具体，但绝不能伪装成作者或讲者的原话。
7. 为章节、概念或难点留下简短来源导航，如章、节、页码、时间戳或锚点。引用只取必要的短句，优先用自己的话概括。

## 写给学习者

- 先解释日常意思，再引入术语。第一次出现的术语要同时给出“它是什么”“在这里有什么用”“别和什么混淆”。
- 把长句拆成因果和步骤；把隐含关系写出来；在必要处补一个贴近当前材料的小例子。
- 不用“显然”“简单”“只要”掩盖难点。读者可能不懂的背景必须被解释或标为待补。
- 不把完整覆盖误写成全文逐句复述。保留每一章的重要论点、逻辑和案例作用，删去不改变理解的重复表述。

## 写入与后续使用

默认在 `./learning-models/` 中创建或更新 `<YYYY-MM-DD>-<topic>.md`。同一材料的新章节、来源定位或更准确解释更新同一个模型；保留修订原因和覆盖范围的变化。

后续使用模型时，说明模型路径、已覆盖范围、核心内容、前置知识桥和学习难点。不要在模型中写练习、掌握结论或学习过程记录。

完成条件：模型按原材料顺序覆盖本次实际处理的内容；核心与延伸清楚分层；概念关系、前置知识、难点和来源导航可用；原材料内容与补充解释没有混淆。
