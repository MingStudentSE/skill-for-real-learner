# 单概念学习闭环

本参考层定义轻量单概念互动教学的可执行规则。它服务互动教学，不替代概念的领域资料。

## 学习闭环

```text
问题或好奇
  → 一个概念 + 可靠来源
  → 已有理解与最小目标
  → 小步解释（定义、边界、机制、适用条件）
  → 暂停输入，接到经验
  → 学习者讲回 / 判断 / 行动
  → 定位差距，提示后重试
  → 已有证据、未验证点、唯一下一步
  → 用户选择：是否保存为模型笔记；选择后由 learn-modeling 建立概念模型
```

## 教学判断

### 问题型与好奇型入口

- **问题型：** 从“下一步要做什么、哪个概念阻塞了它”缩小范围。只学习足以完成一次尝试的最小必要知识。
- **好奇型：** 从“哪里受到了启发、已知道什么”开始。不能因此放弃展示；使用相近构造情境检验判断。

两种入口都不要求学习者先给出完整计划，也都不应升级为整套课程。

### 对一个概念做到一字一义

至少帮助学习者区分以下内容：

| 项目 | 检查问题 |
| --- | --- |
| 定义 | 这个概念在可信来源中通常指什么？ |
| 边界 | 它不是什么；哪些条件下不适用？ |
| 机制 | 条件如何经由过程产生结果？ |
| 当前作用 | 它改变学习者的哪个解释、判断或行动？ |
| 个人表述 | 学习者能否用自己的例子说明，而不偷换概念？ |

个人表述可作为学习者假设，不能冒充来源定义。

### 让输入变成学习

每得到一个可能影响行动的要点，暂停并任选一个问题：

1. 它解释了我遇到的哪个现象？
2. 它和我见过的哪个案例、概念或错误有关？
3. 如果它是真的，我下一次会如何判断或行动？

这样让输入转为思考、连接与验证。

### 反馈与证据

把“答得顺”与“确实能用”分开。优先收集：

1. 不看材料解释概念、边界和机制；
2. 面对输入时作出判断并说明条件；
3. 在真实或相近场景提出行动与观察信号。

反馈要落在定义、边界、关系或条件的具体差距。遵循“提示一次 → 再试一次 → 短解释 → 新情境检验”，不要替学习者把答案直接做完。

### 反思

行动或练习有结果后，不问笼统的“学得好不好”，而是依次查看：结果、原假设、差距、修正和下一步。单次结果只提供有限证据；它可以校正下一轮，不足以宣布概念已经掌握。
