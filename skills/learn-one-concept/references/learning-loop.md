# 单概念学习的分支判断

本参考层只定义轻量单概念回合中会随学习者处境变化的选择。执行顺序与完成条件以 `SKILL.md` 为准；概念定义与安全要求以可靠领域资料为准。

## 入口分支

- **问题型：** 从下一步行动及其概念阻塞缩小范围，只补足完成一次尝试所需的知识。
- **好奇型：** 从吸引学习者的现象和已有理解开始；没有真实场景时，使用相近构造情境检验判断。

两种入口都停留在一个概念，不扩展成主题课程。

## 展示分支

根据当前最缺的证据只选一种展示：

| 证据缺口 | 最小展示 |
| --- | --- |
| 定义、边界或机制是否已经重建 | 不看材料解释概念，并区分一个易混淆反例 |
| 能否识别适用条件 | 面对给定输入作出判断并说明理由 |
| 能否改变实际选择 | 在真实或近真实情境中提出行动与观察信号 |

构造情境只检验判断，不冒充学习者的真实经历或行动证据。

## 纠偏阶梯

先把差距定位为定义、边界、关系或适用条件，再依次升级介入：

1. 给一个只指向该差距的提示，让学习者再试一次。
2. 仍未打通时，提供简短且有来源依据的解释。
3. 换一个相近但不相同的情境，让学习者重新判断。

新情境回答足以核对原差距时停止纠偏；仍不足时，记录唯一的证据缺口并将它作为下一步。
