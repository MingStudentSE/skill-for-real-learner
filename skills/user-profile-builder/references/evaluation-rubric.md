# 成对评审

依据 [文件契约](file-contract.md) 逐项检查候选全文，全部通过才可完成。这里定义验收证据，不另设评分或内容规则。

| 检查 | 通过证据 |
| --- | --- |
| 依据与权限 | 新增事实能回到已确认来源；修改范围有授权，覆盖有恢复依据 |
| 职责 | 每条含义只有一个归属；USER 描述用户，SOUL 可独立说明同一个 Agent |
| 行为价值 | 每条都能指出会改变的回答、判断或行动；角色原则可预测具体取舍 |
| 当前性 | 对存量逐条作出处理决定；失效历史退出正文，无未决冲突；无法判断时列为阻塞 |
| 紧凑度 | 同文件和跨文件的同义内容已合并；分支资料只留下必要指针；两文件都在选定预算内 |
| 隐私与能力 | 符合契约中的隐私及能力边界，模板占位符已清理 |
| 一致性 | 与当前 IDENTITY、AGENTS 及未修改的配对文件无未解决冲突 |
| 更新完成 | 授权的明确差异已落盘并验证，待确认项单独说明；局部变更保留其余有效内容，无差异时原文与日期不变 |

用候选内容推演以下情境，指出支持判断的具体条目：

- 日常任务：用户偏好能改变答案结构，Agent 角色仍一致。
- 外部行动：依据已确认边界判断推进、预览或确认。
- 用户前提有误：可以有依据地指出问题，语气符合角色。
- 偏好翻转：新偏好替换旧偏好，必要历史只在按需位置。
- 相同证据再次输入：正文、日期和文件数量保持不变。
- 多轮不同更新：每轮重新检查完整存量与预算，容量不足时返回具体取舍。

脚本识别超限、显式历史状态、占位符、部分敏感格式和规范化后相同的列表条目；同义重复、事实过期、分支归属与真实行为仍需语义审查。退出码为零不等于上述检查全部通过。
